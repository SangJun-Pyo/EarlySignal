## 검수와 반영
- `docs/Reviews/R01-methodology.md`: 월말 경계·현재 스냅샷 한계·자유서술 식별정보·검증 집단 비대칭·제외 인용 재진입 검수.
- ADR-010: 병렬 역할과 증거 기록. ADR-011: 접수일 기준 과거 재현 주장 범위. ADR-012: 자유서술 검사와 라벨 출처.
- 사람이 검수하지 않은 라벨은 사람 검수 결과로 기록하지 않음.

- R03: 공개 신고·근거 전수 대조, AI 요약/원문 분리, 한국어 조사 식별값, 부분 캐시 차단과 누적 비용 검수.
- ADR-014: 시험을 재개해도 50개 고정 표본을 유지하고 Retry-After를 따른다.

- R04: 실제 브라우저에서 인용·제외, 잘못된 번호 차단, 요청서 두 번 저장·다운로드·이력 유지, 모바일·기준 월 변경을 확인했다.
- 공개 전 별도 검수: Git 후보·정적 빌드의 비밀값 검출 0, 공개 JSON 42개 SHA256 일치, 계약·근거·LLM 연결 테스트 31개 재통과.
- R05: 실제 LLM 호출 없이 상황 요약 입력 범위·출처·비용·중단 조건 검수. 발견한 3개 우회·정렬 문제를 수정하고 별도 실행으로 재검수했다.
