# S38 — 발표 3D 시각 개선

- 시각: 2026-10-09, 완료
- 관련: SPEC §1 발표, ADR-026, `codex/presentation-3d`

## 목표
사용자가 제공한 Truve PPTX/PDF의 표지·마무리·3D 표현을 참고해 예선·결선 발표 자료를 꾸민다.

## 완료 기준
- [x] 예선 18장·결선 21장과 본문 9장·시간 배분 유지
- [x] 기존 통계·원문 캡처·숫자·사건 날짜·한계 및 근거 보존
- [x] 표지·본문 설명·마무리에 새 3D 이미지 반영
- [x] 전 페이지 렌더·텍스트 검사와 구현자 외 독립 검수
- [x] 원본 보존, 편집 원본·생성 프롬프트·신규 출력과 QA 기록

## Codex에 맡긴 일
Truve 레퍼런스의 시각 방향 분석, 이미지 생성, 기존 PDF 편집 원본 활용, 두 버전 제작 및 검수.

## 결과
- 기존 편집 환경인 ReportLab과 pypdf를 사용해 별도 `-3d.pdf` 두 개를 제작했다. 본문 각 1·2·3·9쪽을 교체하고 통계·캡처·부록 31쪽은 원본 PDF 페이지를 복사했다.
- built-in image_gen으로 생성한 개념 이미지 4개와 프롬프트·해시를 저장했다. Truve의 브랜드나 금융 모델은 복사하지 않았다.
- 전체 39쪽 Poppler 렌더 완료. 수정 8쪽은 별도 `reference_review` 에이전트가 1600px로 독립 검수했으며 영역 밖 문자 0개·수치 누락 0개·가독성 차단 0건이다. 나머지 31쪽은 원본 대비 픽셀과 추출 텍스트가 정확히 일치한다.
- 예선 18쪽·결선 21쪽, 본문 9쪽, 시간 240/480초·질의응답 120초 유지. 통계 근거 테스트 6개 통과. 공개 데이터·제품·기존 QA·최종 PDF·사용자 복사본은 수정하지 않았다.
- 검수 근거: `docs/Reviews/R11-presentation-3d.md`, `docs/presentation/qa-3d.json`.
