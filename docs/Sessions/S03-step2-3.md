# S03 — Step 2–3 범위와 키워드 라벨

- 시각: 2026-10-09 완료
- 관련: SPEC Step 2–3, ADR-001, ADR-004, ADR-005

## 목표
사전 등록 사례·대조군의 접수일 범위와 데모 범위를 만들고 16개 증상 키워드 라벨을 부여한다.

## 완료 기준
- [x] scoped·demo 건수 출력 및 기준값 차이 설명
- [x] primary 1개, secondary 최대 2개; 범주·복수형·loss of power 테스트

## Codex에 맡긴 일
사례 목록은 정답 용도만 사용한다. 감시 단위는 브랜드+모델이며 연식은 탐지 입력에 쓰지 않는다.

## 결과
scoped 122,989건(사전123,138보다149적음), demo 7,502건 정확 일치. 현대·기아7,433건+볼트69건. labels_kw 122,989건, 범주16개·primary1개·secondary≤2. 키워드 변형 테스트1개 통과.

## 문제와 해결
정확한 달력 [odate−48개월,odate+6개월) SQL을 사용. end 포함 시123,102건, 시작월초로 확장 시123,980건, 전월전체로 확장 시125,035건임을 확인. 어느 것도 사전123,138건과 같지 않으며 기준값에 맞추기 위해 범위를 바꾸지 않았다. 사전 원형 코드 미제공으로 차이 원인 완전 재현은 미확인.
