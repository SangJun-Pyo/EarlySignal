# S39 — README 다운로드 URL·참고 크기 표시

- 시각: 2026-10-09 (Asia/Seoul)
- 관련: SPEC Step9, ADR-008, 이슈 #33

## 목표
README의 원본 ZIP 표에 실제 URL과 사용자 제공 참고 크기를 표시하고 요청한 순서로 정리한다. 기존 URL·용도와 데이터 범위 설명은 유지한다.

## 완료 기준
- [x] 기존 ZIP URL4개 완전 일치·표시 순서·참고 크기 확인
- [x] 로컬 링크·diff 검사
- [x] 소유3파일 변경·커밋 준비

## Codex에 맡긴 일
README·이 세션·CODEX_LOG만 수정한다. 주저장소 checkout·사용자 미추적 자료·제품 코드·통계·PDF·원본·API·DB에 접근하거나 변경하지 않는다.

## 결과
ZIP 표를 실제 URL이 보이는 autolink로 바꾸고 조사파일·2015~2019·2020~2024·2010~2014 순서로 정리했다. 사용자 제공 약4/78/72/69MB 크기를 추가하고 참고용 반올림 값·원본 갱신 가능성을 명시했다. 기존 용도와 수집/분류 범위 설명은 유지했다.

기준 커밋a3b94bf와 URL4개를 완전히 대조했고 순서·크기·각 파일 용도 일치를 확인했다. 소유 문서의 로컬 Markdown 링크40개 누락0, `git diff --check` 통과. 문구 변경이므로 제품 테스트·HTTP 요청·다운로드·API·DB·통계·PDF 생성은 실행하지 않았다. PR 생성 후 URL·head를 총괄에게 전달하며 실제 CI·독립 검수는 아직 완료했다고 주장하지 않는다.
