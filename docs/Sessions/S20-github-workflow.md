# S20 — GitHub 작성자와 이슈·PR 작업 방식

- 시각: 2026-10-09
- 관련: ADR-022

## 사람이 결정한 것
사용자는 커밋 작성자가 Mac으로 보이는 문제를 지적하고 사용자 이름 또는 Codex 표기를 물었다. GitHub 계정의 실제 표시 이름과 noreply 주소로 이 저장소의 앞으로 작성할 커밋을 설정했다. 이어 이슈→하위 브랜치→서브에이전트 구현→PR 방식을 제안해 채택했다.

## 실제 적용
- 이슈 #1: 전체 LLM 분류·근거 요약 연결과 검증 결과 반영. 진행 중인 작업을 `codex/llm-evidence-validation`으로 옮겼다. 작업 파일과 API 실행은 유지했다.
- 이슈 #2: 이슈 기반 PR 작업을 위한 자동 검증 추가. origin/main 기준의 별도 managed worktree를 만들고 구현 에이전트에게 `codex/pr-checks` 작업을 맡겼다.
- 구현자 외 독립 검수와 기존 이력을 보존하는 merge commit을 절차에 추가했다.
- 과거 Mac 작성자 커밋은 수정하지 않았다. 전환 이후 실제 PR·검수 결과는 이 세션에 이어 기록한다.

## 완료 기준
- [x] 저장소 작성자·커미터 설정 확인
- [x] 중복 없는 이슈와 작업 브랜치 준비
- [x] 새 병렬 작업을 별도 worktree에 배정
- [ ] 실제 PR과 독립 검수·CI 연결
