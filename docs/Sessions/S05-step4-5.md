# S05 — Step 4–5 집계·탐지·미래 정보 차단

- 시각: 2026-10-09 완료
- 관련: SPEC Step 4–5, ADR-001~003, ADR-011

## 목표
브랜드+모델×증상×접수월 고유 신고 수를 집계하고 고정 포아송 규칙으로 감시한다.

## 완료 기준
- [x] primary/secondary 중복을 ODINO 고유값으로 제거
- [x] 0개월 채움, 직전 12개월 평균·6개월 이력·λ 바닥·경보·streak 확인
- [x] 여러 cut-off에서 완료된 월의 전체/절단 결과 정확 일치

## Codex에 맡긴 일
탐지에는 조사 결과·사고일·부품 분류를 전달하지 않는다. 날짜 차단은 원본 신고 필터부터 적용한다.

## 결과
105개 감시 그룹, 190,464개 월×범주 칸, 경보817개. 실제 데이터 전체에서 38개 조사별 완료월 cutoff로 다시 집계·탐지: 38/38 완전 일치(126.3초). 기록 data/results/lookahead_kw.json. pytest 전체23개 통과(다른 에이전트의 LLM·privacy 테스트 포함). 검수로 라벨 누락 fail-fast, llm는demo 범위, 중복월·빈월 검사 추가.

## 문제와 해결
월중 cutoff는 미완료 월을 만든다. 전체 최종월과 비교하는 테스트에서는 그달을 제외하고, 미완료 월의 미래 신고가 제외됨을 별도 확인한다.

## 사람이 검토하며 고친 것
검수 에이전트 권고를 반영해 확인가능일 기준 경계를 ADR-011로 명시(부모 에이전트 기록).
