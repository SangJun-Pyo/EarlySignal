## 목표
실제 키워드 파이프라인을 8개월·9차종 조사 준비 콘솔과 38개 사례·검증 메타로 내보낸다. LLM 측정이 완료되지 않은 상태는 명시하고 빈 요약을 유지한다.

## Codex에 맡긴 일
keyword-only 콘솔을 우선 전달해 웹 구현을 시작하게 한다. API 호출·불완전 LLM50건의 혼합계산·forecast는 하지 않는다.

## 결과
42개 JSON(콘솔·meta·cases·38개상세·완료manifest)을 생성. 콘솔 2,142개 신고/400개 근거 칸/9차종/8개월/9증상. keyword 출처·플래그 출처·심각도/한국어 요약 null, briefs {}. 스키마·SHA256 manifest·evidence ID/n/agg/co/year·snapshot count/ratio·사례 lead·운영 미래값 분리·public_text known denylist 검사와 brief negative tests 포함 인계 직후 전체 Python 48개 통과. 이후 LLM 연결 테스트는 S07b에 별도로 기록했다.

## 문제와 해결
불완전한 LLM50건을 전체 데이터와 혼합하지 않았다. 데이터는 키워드 기준선임을 구조로 명시한다. 아직 측정하지 않은 정확도·비용은 null, 검수 수는0으로 내보낸다. 개인정보 필드 제외와 별도로 자유서술을 알려진 VIN·도시·딜러·운전자 값과 정규식으로 보수적으로 가린다. 모든 이름을 탐지한다고 주장하지 않는다.

## 사람이 검토하며 고친 것
부모가 keyword-only·nullable severity·출처 명시를 지시했고 독립 검수에 전달했다.
