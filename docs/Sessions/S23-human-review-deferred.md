# S23 — 독립 사람 검수의 당일 미완료 결정

- 시각: 2026-10-09
- 관련: SPEC Step 7, ADR-020, GitHub 이슈 #7

## 목표
사용자의 검수 중단 결정을 정확히 기록하고 미측정 성능이 확인된 성능처럼 보이지 않게 한다.

## 완료 기준
- [x] 자료 준비와 실제 검수 완료를 구분하고 중단 이유를 기록한다.
- [x] 평가 구현을 중단하고 사람 정답을 AI가 보충하지 않는다.
- [x] 사람 정답 기준 분류 정확도를 미측정으로 유지한다.
- [x] 발표 담당자에게 같은 결정과 후속 검증 범위를 전달한다.

## Codex에 맡긴 일
독립 30건 자료를 준비하고 평가 도구 구현을 시작했으나, 사용자 결정 후 해당 서브에이전트 작업을 중단했다. 미완성 구현은 제품에 통합하지 않고 복구 가능한 worktree 보관으로 남긴다.

## 결과
사용자가 원문 검수를 시도했지만 필요한 도메인 지식이 부족하고 공모전 안에 완료하기에는 시간이 많이 든다고 판단했다. 사람 정답 0건, 정확도 평가 미실행이다. 평가 도구의 추가 커밋·push·PR·테스트 실행은 없었다. 기존 30건 표집·예측 가림·정답 보존 기능은 후속 검수 준비로 유지한다.

출력 형식·원문 인용 일치 검사는 의미 정확도를 증명하지 않는다. 키워드와 LLM의 일치율은 두 방법의 합의 정도이며 사람 정답 정확도가 아니다. 백테스트는 정해진 조건에서의 경보 시점 검증이며 개별 분류 정답 검증을 대신하지 않는다.

## 문제와 해결
| 문제 | 원인 | 해결 | 누가 |
|---|---|---|---|
| 당일 독립 정답 확보 불가 | 도메인 지식과 시간 제약 | 미완료 이유를 공개하고 전문가 검수를 후속 과제로 이관 | 사람 결정 / Codex 기록 |

## 사람이 검토하며 고친 것
- 직접 30건을 검수하기로 했던 결정을 변경해 이번 제출에서는 진행하지 않도록 요청했다.

## 다음 세션으로 넘길 것
- 전문가가 원문만으로 판단 가능한 범주 정의를 검토하고 독립 표본의 정답과 모호함을 판정한다.
- 사이트·PDF에는 미측정 정확도와 실제 수행한 자동 검증·백테스트를 구분한다.
- 독립 Codex 검수: ADR·명세·준비 이력·현재 상태의 구분과 중단 기록이 일치함을 읽기 전용으로 확인했다. 정답 CSV는 열람하지 않았다. 후속 검수 재개 시에는 지침의 상태 문구 추가로 기존 `rubric_hash`와 달라질 수 있으므로 기존 준비 버전과 새 검수 기준의 차이를 기록하고 잠금을 임의로 덮어쓰지 않는다.
