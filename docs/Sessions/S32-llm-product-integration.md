## 실행 중 확인
- PR #19의 이메일 패턴 경계 보완을 독립 검수와 실제 CI 성공 후 병합했다. 합성 한글 인접 이메일 누락 보완이며 실제 누출이 발견됐다는 뜻은 아니다.
- 기존 자유 종합 후보는 의미상 과한 일반화로 공개 거부했다. 사용자 승인 후 번호만 선택하고 기존 AI 요약을 그대로 인용하는 ADR-024를 적용했다.
- 새 모드 첫 경보 1개 성공 후 나머지 17개를 실행했다. 15개 성공·2개 실패, 이전 1개 재사용으로 공개 가능한 요약은 16/18개다. 두 실패는 기존 요약의 수량 표현 검사에 걸렸고 최대 재시도 후 요약 없이 남긴다. 검사를 완화하거나 문장을 고치지 않았다.
- 16/18은 출처·형식 검사 결과이며 원문 의미 또는 분류 정확도가 아니다. 사용자의 당일 사람 검수 취소에 따라 사람 정답은 0건, 정확도는 미측정이다.

## 사람이 검토하며 고친 것
- 서로 다른 신고를 한 문장으로 합성하지 않고 신고별 AI 요약과 번호를 연결하도록 선택했다.
- 사람 정답 검수는 도메인 지식과 공모전 시간 제약으로 당일 진행하지 않고, 그 한계와 후속 전문가 검수 계획을 공개하도록 결정했다.

- 최종 export: 45JSON·2,142신고·421근거칸·16대표 요약, 전체 7,502건 현재 캐시 검사 통과.
- 테스트 첫 실행은 export와 겹쳐 실제 DB 읽기 잠금 1건이 실패했다(223통과). export 종료·DB 연결 해제 뒤 전체를 다시 실행해 224개 통과(27.16초). 테스트를 제외하거나 잠금 규칙을 변경하지 않았다.
- 웹23 tests·타입 검사·Next 정적 빌드 통과.
- R08 독립 검수: 현재 대표 요약16개의 선택 인용47개·통계문 재구성 일치, 구 종합 후보 공개0개, 실패2개 미표시. 최종45JSON·44payload SHA·18,902공개문자열+16요약 알려진 식별값 검사 통과.
- 총괄은 R08 원본 파일8개의 해시와 라벨/요약 원장의 정수 토큰을 독립 십진 검산했다. 누적 라벨$4.5448836+요약$0.0292060=총$4.5740896. 청구서·계정잔액·사람 정확도와 구분한다.
- PR20/21: 총괄 독립 검수와 실제CI 성공 확인 뒤 merge commit으로 통합. PR21의 분류·대표선택 프롬프트는 변경 전후 문자열이 동일하며 계약 데이터 구조 변경 없음.
- Cloudflare branch preview에서45JSON이 최종 파일 SHA와 전부 일치했다. 실제 #11115234인용·#11118964제외, 대표요약3개 유지, 조사착수·원문정밀검토·메모 선택 후 확정 및 Markdown다운로드 확인. 검증 화면에는 키워드주결과·LLM7502·사람정답0·정확도미측정 표시. 근거는 deployment_llm_preview.json.

## 후속 질문에서 확인한 범위와 비교 맥락
- 사용자가 2024년까지 확장할 필요와 실제 2018년 사건을 물었다. 조회만 수행했으며 추가 API 분류는 실행하지 않았다. 현재 9개 차종을 같은 시작일2017-03에서2024-12까지 늘리면28,224건(현재7,433건+추가20,791건)이다. 기존7,451건 배치 실적의 단순 환산은 약72분·$12.51이며 운영·오류·원문 길이에 따라 달라지고 실제 실행 견적은 아니다.
- 사용자는 현재 범위를 먼저 완성하고 기간 확장은 후속 실험으로 남기기로 결정했다. 기존 모집단·기간·탐지 규칙을 유지한다.
- NHTSA 공식 PE19003/4 개시 문서를 확인해 2019-03-29 이전에 CAS청원2018-06-11·DP18-003검토2018-08-21과 기존리콜조사가 있었음을 확인했다. '최초 발견'으로 읽히지 않도록 이슈#22를 등록하고 지정PE대비 표현과 공식 맥락을 보완한다. 이는 사후 설명이며 탐지 입력에 추가하지 않는다.
