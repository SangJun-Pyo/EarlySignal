## 실행 중 확인
- PR #19의 이메일 패턴 경계 보완을 독립 검수와 실제 CI 성공 후 병합했다. 합성 한글 인접 이메일 누락 보완이며 실제 누출이 발견됐다는 뜻은 아니다.
- 기존 자유 종합 후보는 의미상 과한 일반화로 공개 거부했다. 사용자 승인 후 번호만 선택하고 기존 AI 요약을 그대로 인용하는 ADR-024를 적용했다.
- 새 모드 첫 경보 1개 성공 후 나머지 17개를 실행했다. 15개 성공·2개 실패, 이전 1개 재사용으로 공개 가능한 요약은 16/18개다. 두 실패는 기존 요약의 수량 표현 검사에 걸렸고 최대 재시도 후 요약 없이 남긴다. 검사를 완화하거나 문장을 고치지 않았다.
- 16/18은 출처·형식 검사 결과이며 원문 의미 또는 분류 정확도가 아니다. 사용자의 당일 사람 검수 취소에 따라 사람 정답은 0건, 정확도는 미측정이다.

## 사람이 검토하며 고친 것
- 서로 다른 신고를 한 문장으로 합성하지 않고 신고별 AI 요약과 번호를 연결하도록 선택했다.
- 사람 정답 검수는 도메인 지식과 공모전 시간 제약으로 당일 진행하지 않고, 그 한계와 후속 전문가 검수 계획을 공개하도록 결정했다.

- 최종 export: 45JSON·2,142신고·421근거칸·16대표 요약, 전체 7,502건 현재 캐시 검사 통과.
