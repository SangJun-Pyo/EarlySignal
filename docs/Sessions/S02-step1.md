# S02 — Step 1 ZIP 적재

- 시각: 2026-10-09 완료
- 관련: SPEC Step 1, ADR-002, ADR-008

## 목표
원본 ZIP을 DuckDB에 적재하고 소비자 차량 신고를 ODINO당 한 행으로 만든다.

## 완료 기준
- [x] 원본·고유 신고·조사 건수와 LDATE 파싱 실패 확인
- [x] 식별번호·차종·접수일만 5건 출력
- [x] 필터·중복제거·날짜·따옴표 처리 테스트

## Codex에 맡긴 일
51열 TSV의 따옴표 해석을 끄고 zip을 안전하게 펼친다. 날짜·유형 필터를 적용하고 비밀값·개인정보를 로그에 출력하지 않는다.

## 결과
원본 1,301,663행 / 소비자 고유 932,821건 / LDATE 파싱 실패 0건. 조사 154,429행 / 고유 5,349건. 안전한 메타데이터 샘플 5건 출력. 적재 테스트 1개 통과.

## 문제와 해결
사전 신고값 932,837보다 16건 적음. SQL로 PROD_TYPE=NULL 소비자 ODINO가 정확히 16건임을 확인(규칙 V를 유지). 사전값이 NULL을 포함했는지는 원형 코드 미제공으로 확정할 수 없다. 조사 원본은 사전값보다 28행 많아 현재 ZIP 스냅샷 차이 가능성; 고유 조사 수 동일.
