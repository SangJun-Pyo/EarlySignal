# S35 — Step 9: 공개 제품 문구 전수 최신화

- 시각: 2026-10-09 (구현·로컬 검증)
- 관련: SPEC Step 9, ADR-024·025, [이슈 #27](https://github.com/SangJun-Pyo/EarlySignal/issues/27)

## 목표
화면·메타데이터·다운로드 요청서의 사용자 노출 문구를 현재 공개 결과와 사용자 승인 소개 문구에 맞춘다. 실제 요청서 초안, 과거 재현, 사람 정답 정확도 미측정과 키워드 주 검증의 한계는 유지한다.

## 완료 기준
- [x] 추적된 웹 사용자 노출 문자열을 전수 검색하고 변경·유지 이유를 기록한다.
- [x] 승인 슬로건과 공개 파일 기반 상태를 반영하며 실시간 연결·미완료 제품으로 오해할 표현을 정리한다.
- [x] 데이터·API·탐지·요청서 동작은 바꾸지 않고 기존 웹 검사·타입·빌드를 통과한다.
- [ ] 별도 브랜치·PR·독립 검수로 통합한다.

## Codex에 맡긴 일
origin/main 77ce5be의 새 managed worktree에서 codex/current-public-copy로 작업한다. 소유 범위는 web 사용자 문구·메타데이터·요청서 텍스트와 본 세션이다. README·STATUS·CODEX_LOG는 별도 담당이며 파이프라인 export 문자열 변경은 총괄에게 제안만 한다. `.env`·API 키·DB·raw·private 자료는 읽지 않는다.

## 점검 범위와 변경·유지 이유
root AGENTS → WORKFLOW → SPEC Step9 → ADR024/025 → 계약 → web AGENTS를 읽었다. 잠금 의존성 설치 후 로컬 Next16.4 문서의 metadata와 static export 가이드를 확인하고 정적 metadata 방식과 클라이언트 파일 로딩을 유지한다. 새 설계·계약 변경 없이 기존 ADR의 표시를 현재 결과에 맞춘다.

`web/app`, `web/components`, `web/lib`의 추적 파일을 읽고 한국어 문자열·조건부 출력·title/aria/placeholder와 “50건/36건/검증용/준비/초안/연결/사전/실시간/식별/요약”을 전수 검색했다. CSS의 사용자 생성 내용은 구분점뿐이며 `web/public/_headers`와 설정·타입은 사용자 소개 문구를 담지 않는다. tests의 합성 예시는 제품 문구로 취급하지 않았다. 공개 JSON의 출력 문구·현재 출처와 수치도 읽기 전용으로 대조했다.

사용자 화면에 50/36건 시험을 최신 상태로 표시한 문자열은 없었다. 36대조는 실제 키워드 평가 표본 수이고 60건 비교 파일은 개발 자료다. 신고 자체 원문·AI 요약·NHTSA 사례 제목은 근거 데이터이며 문구 수정 대상에서 제외했다.

## 결과
- 현재 JSON 확인: labeler=llm, 7,502건 분류, 사람정답0건·정답 일치 값 null, 38사례 키워드 결과, 대표 요약16개. 숫자를 새로 하드코딩하지 않았다.
- 공개 JSON45개가 base77ce5be와 바이트 단위로 모두 동일하다. 파이프라인·API·DB·키·raw·private 접근이나 변경은 없다.
- 기존 웹26검사가 통과했다. 빈 대표 요약 문구·알려진 식별정보 설명과 실제 초안/확정 상태를 기존 요청서 검사에서 확인했고, 실제 labeler 출처 SSR 검사도 갱신했다. 새 테스트 파일·모사 테스트는 만들지 않았다.
- 최종 `npm run typecheck`와 `npm run build` 통과. prebuild의26검사도 통과했으며 정적 `/`·`/_not-found` 생성. 실제 `web/out/index.html`의 제목·description에 승인 슬로건과 접수일 기준 과거 재현이 들어 있음을 확인했다.
- `git diff --check` 통과. 변경은 웹5파일(표시3·기존검사2)과 본 세션으로 한정된다. README·STATUS·CODEX_LOG·package lock·web AGENTS·공개 JSON·파이프라인은 수정하지 않았다.
- 이슈27의 웹 부분은 main 대상 Draft PR과 최신 CI·구현자 외 검수로 넘긴다. PR/CI 실제 결과는 총괄에게 메시지로 전달하며 성공 기록만을 위한 추가 커밋 반복은 하지 않는다.
- 통합용 색인 제안: `S35 | 9 공개 문구 | 10/9 | Sol 구현 / 별도 검수 예정 | 승인 슬로건·공개 파일 과거 재현·완료된LLM분류·요약없음 상태로 갱신; 웹26·타입·빌드, JSON45불변 | 사용자 전수 최신화 요청`.
