# S41 — 발표자 이름과 제출 PDF 마감

- 시각: 2026-10-09, 완료
- 관련: SPEC §1 발표, ADR-026, 이슈 #39

## 목표
사용자가 확인한 이름 표상준을 발표자료·대본에 추가하고, 효과가 큰 디자인 수정만 반영해 제출본을 제공한다.

## 완료 기준
- [x] 예선20쪽·결선23쪽·대본10쪽, 발표자와 작성자 메타데이터 확인.
- [x] 7쪽 그래프의 분모별 비율을 수정하고 실제 수치·문구 보존.
- [x] 변경 쪽 렌더·전체 텍스트·수정 없는 쪽 보존·독립 검수.
- [x] 현재 파일 안내·검수·세션 기록 갱신 후 커밋·PR.

## Codex에 맡긴 일
최종 디자인 평가, 이름 배치, 그래프 비율 수정, PDF 보존 검증과 독립 검수.

## 결과
- 예선20쪽·결선23쪽·대본10쪽의 최종 PDF 3개. 표지·본문9쪽·대본 첫 쪽에 `발표자 표상준`, 메타데이터 Author는 표상준이다.
- 전체53쪽의 기존 텍스트 보존, 수정 없는46쪽의 decoded content stream·페이지 영역 일치. 기존 v2·대본 입력 해시를 그대로 유지했다.
- 별도 `reference_review`가 변경7쪽을 최신 출력에서1600px로 렌더해 검수했다. 이름 겹침·잘림 없음, 전체 영역 밖·대체 글리프0개다.
- 실제 PDF 벡터 트랙646pt, 채움306/0/238/38pt로 9/19·0/19·7/19·1/17 비율을 독립 확인했다. 같은17분모 대조 막대만34pt에서38pt로 바로잡았다.
- `py_compile`, 빌더 입력/차트텍스트 보호 검사, `git diff --check` 통과. 제품·공개JSON·통계 규칙은 변경하지 않았다.
- R13·qa-final.json·final-build-manifest.json에 범위·해시를 기록했다. 현재 안내 링크는 새 제출본을 가리킨다. 실제 타이머 리허설은 수행하지 않았다.

- 디자인 개선 효과가 미비하면 기존 구도를 유지하도록 요청했다.
