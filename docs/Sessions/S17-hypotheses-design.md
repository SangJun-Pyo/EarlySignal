# S17 — 조사 가설과 확인 절차의 설계 범위

- 시각: 2026-10-09 11:30 KST부터
- 관련: ADR-019, 제품·발표 범위

## 목표
현재 제품을 먼저 완성하면서 사용자가 요청한 실무 조사 확장 방향을 설계와 발표에 기록한다.

## 완료 기준
- [x] 사용자 선택과 현재 데이터·기능의 한계를 ADR에 기록
- [x] 확인된 내용·조사 가설·필요 자료·확인 결과를 구분
- [x] 발표와 독립 검수에 반영

## Codex에 맡긴 일
총괄이 ADR-019를 작성하고 발표 담당에게 후속 설계 표기와 시간 배분 유지를 요청했다. 가설 생성 코드·API 호출·통계 규칙은 추가하지 않았다.

## 결과
현재 제품은 과거 접수 신고의 안전 신호와 조사 요청서를 제공한다. 새 VOC 연결, 정비·생산 자료 검색, 가설 생성은 미구현이다. 선행일수는 공식 조사 개시 전 기간이며 사고 발생 전 성능이 아니다. 후속 설계는 근거와 반례, 필요 자료, 담당자 확인을 연결한다.

## 사람이 검토하며 고친 것
사용자가 현재 제품 완성을 우선하고 가설·확인 절차는 설계와 발표에 추가하기로 선택했다.

## 다음 세션으로 넘길 것
실제 현업 담당자의 업무 확인과 자료 접근 가능성, 추가 기능의 평가 표본·판정 기준 수립.

발표 담당이 두 PDF의 공통 부록에 후속 설계 흐름을 추가했다. 별도 검수자가 실제 기능으로 오해할 부분을 검토했고, '확인된 내용'을 '원문에 명시된 내용'으로 고쳤다. 4분/8분 본문 시간은 유지했다.
