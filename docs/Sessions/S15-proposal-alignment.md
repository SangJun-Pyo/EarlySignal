# S15 — 제출 기획과 구현 범위 대조

- 날짜: 2026-10-09 (Asia/Seoul)
- 요청: 사용자가 공유한 제출 기획과 현재 방향의 차이, 판단 이유를 남긴다.
- 관련: ADR-009·016·017, 발표 자료

## 계획과 완료 기준
- [x] 사용자가 공유한 제출 기획을 기록하고 기능별로 실제 구현과 대조
- [x] 유지·구체화·미구현·임시 기준선을 구분
- [x] 사전 결정과 당일 제약, 현 시점의 판단을 구분
- [x] 별도 에이전트의 사실·범위 검수와 발표 부록 대조표 확인

## 결과
ADR-017에 기획 원문, 8개 대조 항목, 구현 순서의 이유와 남은 검증 조건을 기록했다. 요청서 중심 흐름은 기존 담당자 결정을 구체화했다. 유사 사례 검색과 별도 부품 추출은 현재 미구현이며, 키워드 배포는 AI 효과가 입증되기 전 기준선 상태다. 사전 문서나 원래 기획을 덮어써 차이를 지우지 않는다.

## 사람이 결정한 것
사용자가 '분류 검증 우선 + RAG 근거 검색 확장 설계'를 선택했다. 이는 실제 DB·API 구현이나 추가 API 비용 승인이 아니다. 이어 제출 기획과 달라진 범위와 판단 이유를 기록하도록 요청했다.

## 다음 확인
독립 검수 후 발표 근거표와 Codex 색인에 연결한다. 실제 모델·검색 품질이 확인되면 기존 기록을 지우지 않고 후속 결과를 추가한다.

독립 검수에서 원안 내용 보존과 구현 범위 일치를 확인했다. 제안 2건을 반영해 Step10의 오프라인 구현 상태를 갱신하고 실제 공개 배포 검증 파일을 근거로 추가했다.
