## 목표
전체 LLM 내보내기의 실제 월별 집계·포아송 경보·분류 비교·비용·최종 요청서 캡처를 발표에 연결한다. 38사례 키워드 주 검증은 보존하고 사람 정답 정확도와 방법 간 일치율을 구분한다.

## 완료 기준
- [ ] 월별·포아송 그림과 문구가 현재 console의 라벨 출처·수치와 일치
- [ ] 38사례 주 결과는 키워드 기준선이라고 표시
- [ ] LLM 일치율·출력 검사·사람 정답 평가를 구분
- [ ] 실제 비용·실패와 개선·최종 캡처를 원본 결과에 연결
- [ ] 예선 240초, 결선 480초+질의응답 120초 유지
- [ ] PDF 전체 렌더·독립 검수·노트/근거표/QA 갱신
- [ ] 제품 통합 뒤 main 대상 후속 PR과 이슈 연결

## Codex에 맡긴 일
발표·그림 파일만 수정한다. 총괄이 완료된 공개 JSON·결과 JSON·캡처를 전달하기 전에는 추정 수치를 넣지 않는다. 원본 데이터·API·환경변수·사용자 정답 파일은 접근하지 않는다. 공용 CODEX_LOG 색인은 총괄이 통합한다.

## 결과
준비 단계: 기존 그림의 82/12·17건 고정 검사를 현재 console 기반 검산으로 바꾸고 동적 축·문구를 구현했다. 현재 export 대조, 합성 LLM 수치, 미래 월 무영향, 기준선 하한, export 불일치 거부, 이력 부족 거부의 6개 검사가 통과했다. 기존 키워드 결과로 임시 렌더를 만들어 축·글꼴·범례를 확인했다. 발표 생성은 그림의 labeler와 공개 console/meta 해시가 다르면 중단한다. 전체 실측 반영은 총괄의 완료 자료 전달 후 진행한다.

## 사람이 검토하며 고친 것
- 사용자가 이슈→별도 작업트리→PR→구현자 외 검수 절차를 선택했다.
- 독립 30건 검수 자료는 준비했지만, 사용자가 직접 시도한 뒤 도메인 전문성·시간 제약으로 당일 검수를 완료하지 않기로 했다. 사람 정답을 AI로 대체하지 않으며 분류 정확도는 미측정으로 남긴다. 전문가 검수는 후속 계획이다.

## 1차 LLM 내보내기 검산과 대기

총괄이 읽기를 허용한 1차 LLM 공개 내보내기와 동일 모집단 비교 결과로 그림을 임시 생성했다. 데모 SONATA의 직전 12개월 합계 59건, 기준선 4.9166666667건, 관측 17건, 배수 3.4576271186, p=0.0000161302196739가 내보낸 경보와 일치했다. 최종 공개 JSON이나 PDF는 아직 교체하지 않았다.

동일 7,502건의 대표 증상 일치 3,793건(50.56%), 동일 4,464칸의 키워드 34·LLM 39 경보, 현대·기아 선행 209·240일 동일, 볼트 키워드 놓침·LLM 23일 늦음을 표시하는 본문을 준비했다. 방법 간 일치율은 정확도가 아니며 경보가 늘었다는 이유로 우위를 주장하지 않는다. 등록 38사례의 주 결과와 38회 시간 검산·64칸 독립 검산은 키워드 근거라고 명시했다.

총괄 요청에 따라 상황 요약의 인용 검사 실패를 먼저 수정하는 동안 준비 변경을 커밋하고 대기한다. 최종 공개 JSON·비용 감사·상황 요약·제품 캡처를 전달받으면 PDF 전체 생성·렌더·독립 검수·문서/QA 동기화와 부모 PR #4 대상 draft PR을 완료한다. 이번 단계는 최종 발표물 완료가 아니다.

## 대표 신고 요약 선택 반영 준비

부모 `070244c`를 merge commit으로 통합했다. ADR-024에 맞춰 AI는 같은 경보의 신고 번호 1~3개를 선택하고 프로그램은 기존 신고별 AI 요약을 그대로 연결한다는 설명으로 바꿨다. 초기 자유 종합 54응답·0/18 통과, 문장별 구조화 첫 1개 형식 통과 후 의미 과장으로 공개 거부, 기존 요약 인용으로 바꾼 과정을 시간 외 부록 한 장으로 준비했다. 마지막 공개 건수는 현재 console에서 읽으며 최종 출력과 대조할 예정이다. 기존 요약 자체의 의미 정확도도 미측정이라는 한계를 남긴다.

본문 12장의 240초/480초 배분은 유지했다. 이슈→작업트리·브랜치→PR→독립 검수도 발표에 반영했다. Python 구문 검사를 통과했으며 PDF는 최종 LLM 데이터·공개 캡처·비용 검산 전달 후 생성한다. 총괄의 최신 통합 계획에 따라 후속 PR 대상은 제품 PR 병합 뒤 main으로 변경한다.
