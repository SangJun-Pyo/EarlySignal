# 발표 구성 · 고객의 목소리를, 조사의 근거로.

2026-10-09 사용자 확정 구성이다. 예선은 **7장·4분(실제 데모60초 배분 포함)**, 결선은 기존9장의 **8분 발표·데모+2분 질의응답**이다. 예선은 시연에 집중하고 상세 통계·검증을 부록에 둔다. [예선4분 대본 Markdown](presentation/speaker-script-4min.md), [결선·기존 질의응답 대본](presentation/speaker-script-final.md), [근거표](presentation/evidence-manifest.md)를 따른다. 시간은 배분안이며 실제 타이머 리허설은 미완료다.

중심 문장: **고객의 목소리를, 조사의 근거로.** 소비자 신고에서 조사할 후보를 찾고, 담당자가 원문을 검토해 조사 요청서를 완성하도록 돕는다. 더 이른 조사 착수를 지원할 가능성은 있지만 현업 검토 시간·예방 효과는 아직 검증하지 않았다.

## 예선 본문 7장

| 장 | 내용 | 배분 |
|---|---|---:|
| 1 | 2018년 현대·기아 화재 신고 사건으로 문제 제시, 표지 | 20초 |
| 2 | 표현이 다른 신고에서 담당자가 조사할 이유를 찾는 문제 | 30초 |

| 4 | 신호→원문 인용·제외→요약·판단 검토→요청서 저장·다운로드 | 60초 |
| 5 | 직전12개월 평균4.92건→17건·3.46배, 통계 경보의 의미 | 35초 |
| 6 | 키워드38사례 평가와 LLM7,502건 데모 범위·남은 검증 구분 | 40초 |
| 7 | 조사의 근거를 정리하는 가치, 전문가·현업 검증 계획, 마무리 | 30초 |
| 합계 | 본문7장, 실제 데모60초 | **240초** |

결선의 기존9장 배분은 **40·25·45·100·50·65·60·40·55초=480초**다. 4장100초 중 마지막10초에 조사 질문·정비 기록·검사 확인을 후속 설계로만 설명한다. 이어120초 질의응답을 한다.

## 공개 결과를 말하는 범위

- 제품은 LLM7,502건의 출력 검사 완료 결과다. 사람 정답은0건이며 분류·요약 정확도는 미측정이다. 독립30건 자료를 준비하고 사용자가 시도했으나 전문성·시간 제약으로 당일 미완료했다. 전문가 검수가 후속 과제다.
- 주 백테스트는38사례 키워드 결과다. 개발 사례9/19·대조0/19, 검증 사례7/19·대조1/17을 그대로 둔다. 선정 사례의 표적 경보 비율이며 일반 정확도·오탐률·포아송 적합성을 뜻하지 않는다.
- 209·240일은 지정 PE19-003·004의 **2019-03-29 개시일 대비**다. 2018-06-11 CAS청원, 08-21 DP18-003검토와 더 앞선RQ가 있었다. 기관의 최초 인지·최초 조사 또는 AI 최초 발견보다 앞섰다는 주장을 하지 않는다. 공식 이력은 사후 설명이며 탐지 입력에 넣지 않는다.
- 동일 데모의3,793/7,502 라벨 일치는 정확도가 아니다. LLM 경보가34→39로 늘어났다고 더 낫다고 말하지 않는다. 대표사례 비교는 등록 전체 평가창보다 짧다.
- 대표요약은18경보 중16개 공개,2개 수량 검사 실패다. AI는 번호만 고르고 기존 신고별 AI 요약을 그대로 인용한다. 초기 자유종합54응답0/18, 구조화1개 형식통과 후 의미과장 공개거부, 기존요약선택으로 개선한 이력과 실패를 남긴다.
- 누적 실험$4.5740896은 라벨$4.5448836+요약$0.0292060이다. 실패·진단까지 포함한 반환 사용량 추정이며 계정 청구액이나 정확한 건당단가와 다르다.
- 2018년12월 연료관 리콜은 별도 실제 문제 예시다. 이전 리콜로 엔진을 교체한 차량 일부의 연료관 문제를 데모 모든 신고의 원인으로 동일시하지 않는다.
- pgvector/RAG·유사과거사례검색·별도부품추출·정비자료연결·실제 가설생성은 미구현이다. 2024년까지 기간을 넓히는 실험은 후속 과제다.
