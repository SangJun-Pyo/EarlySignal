# EarlySignal 진행 상태

## 사용자 결정
자동차 회사 고객 안전 담당자의 경보 선택 → 원문 검토 → 요청서 저장. 예선4분, 결선8분 발표·데모+2분질의응답, 검증부록. 주장별 근거·실패·미검증 가정을 공개한다. 50건 비용 보고 후 제공된 $50 크레딧으로 전체 실행을 승인했다. 사람 검수는 도메인 지식·공모전 시간 제약으로 당일 미완료를 기록하고 후속 전문가 검수로 이관한다. 기간 확장은 후속 실험으로 남긴다. 발표는 “고객의 목소리를, 조사의 근거로.”를 중심으로 실제 현대·기아 사건에서 시작하는 예선 본문9장으로 확정했다.

## 완료
- 원본 적재·키워드 집계·고정 통계·38사례 평가. 실패 사례와 주 평가/민감도를 구분했다.
- 초기 키워드42 JSON·400근거칸에서 전체 LLM 결과를 반영한45 JSON·2,142신고·421근거칸으로 갱신했다. 38사례 주 검증과74행 결과CSV는 키워드 기준선으로 유지한다.
- [공개 Cloudflare 제품](https://earlysignal.pages.dev/)에 전체 LLM 분류와 대표 신고 요약 인용을 배포했다. 공개45 JSON이 검수본과 일치하고 원문 인용·제외, 요청서 저장·Markdown/JSON 다운로드·재접속 이력을 확인했다. 근거는 `data/results/deployment_llm_verification.json`.
- Python224·웹26 테스트, 타입 검사·정적 빌드 및 main 실제 CI 통과. 라벨 인용 선택·대표 요약·비교 기준 문구는 구현자 외 별도 에이전트가 검수했다.
- 고정50건 API 출력 검사 완료. 6→36→50건 과정의 요청 제한과 인용 실패를 보존했다. 반환 사용량 누적 추정 $0.0593988. 분류 정확도는 아직 미측정이다.
- 초기 발표 중간 검토본41페이지를 검수했다. 이후 전체 LLM 결과·공식 사건 맥락·현재 비용을 반영한 초안을 생성했으며, 최종본 통합 결과는 아래에 기록했다.
- 개발50건과 겹치지 않는 독립 사람검수30건 자료를 준비해 사용자에게 전달했다. 예측은 가리고 정답은 사람이 입력한다.
- 전체7,502건 분류·출처 검사와 같은 모집단 비교 완료. 대표 신고 요약은16/18개 공개, 수량 표현 검사에 걸린2개는 요약 없이 남겼다. 실패·진단을 포함한 라벨·요약 반환 사용량 비용 추정은 합계$4.5740896이며 청구액·잔액이 아니다.
- PR #4·#23을 독립 검수·실제 CI 성공 후 merge commit으로 통합했다. 지정 예비조사 비교와 그 이전 청원·리콜 조사 맥락을 공개 화면에 반영했다.
- 최종 발표 자료를 PR #25·main `7bb64f3`에 통합했다. 예선 본문9+부록9=18페이지, 결선 본문9+부록12=21페이지이며 총39페이지를 구현자 외 검수자가 독립 렌더·검수했다. 수치·출처·캡처와 QA36개 근거 해시가 일치하고 글리프 누락·잘림·겹침은 발견되지 않았다. 내부 초안 표기를 제거했으며 파일명은 기존 링크 보존을 위해 유지한다.

## 제출 준비 상태
제품과 두 발표 PDF·발표자 노트·출처표·독립 검수 기록을 준비했다. 예선9장·통계본문2장·60초 데모를 포함한240초, 결선480초+질의응답120초는 시간 배분안이다. 실제 발화·현장 조작을 포함한 타이머 리허설과 제출은 아직 수행하지 않았다. 제품·자료 통합 이슈#1과 발표 이슈#10의 완료 범위에 실제 시간 리허설을 포함해 주장하지 않는다.
