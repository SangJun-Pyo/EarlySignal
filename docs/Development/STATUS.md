# EarlySignal 진행 상태

## 사용자 결정
자동차 회사 고객 안전 담당자의 경보 선택 → 원문 검토 → 요청서 저장. 예선4분, 결선8분 발표·데모+2분질의응답, 검증부록. 주장별 근거·실패·미검증 가정을 공개한다. 50건 AI 시험 후 전체 실행은 별도 결정한다.

## 완료
- 원본 적재·키워드 집계·고정 통계·38사례 평가. 실패 사례와 주 평가/민감도를 구분했다.
- 키워드42 JSON, 2,142신고·400근거칸·74행 결과CSV.
- [공개 Cloudflare 제품](https://earlysignal.pages.dev/)에서 원문 인용·제외, 요청서 저장·Markdown/JSON 다운로드·이력 유지 확인. 공개42 JSON이 검수본과 일치했다.
- Python174·웹19 테스트 및 정적 빌드. 라벨 인용 선택과 상황 요약은 별도 에이전트가 검수했다.
- 고정50건 API 출력 검사 완료. 6→36→50건 과정의 요청 제한과 인용 실패를 보존했다. 반환 사용량 누적 추정 $0.0593988. 분류 정확도는 아직 미측정이다.
- 중간 발표 검토본: 예선 본문12장 4분+부록7장, 결선 본문12장 8분+Q&A2분·부록10장. 총41페이지 렌더·독립 검수. 월별 집계와 포아송 본문2장, 다른 통계·현재 LLM 방식·미구현 검색·가설 확인 설계 포함.
- 개발50건과 겹치지 않는 독립 사람검수30건 자료를 준비해 사용자에게 전달했다. 예측은 가리고 정답은 사람이 입력한다.

## 진행 중
- 사용자 승인에 따라 전체7,502건 분류와 데모 경보 요약 실행. 제공된$50 크레딧 범위에서 비용·실패를 기록한다. 실제API 응답의5,000RPM·2,000,000TPM 확인. 고정50 시험은 별도 보존하고 전체 배치는 `data/results/llm_batch.json`에 보고한다.
- 실제 사람30건 정답 작성은 사용자가 직접 진행한다.
- GitHub 이슈#1 / 기능 브랜치 / PR#4로 통합을 추적한다. 이슈#2의 PR 자동 검증과 이슈#3의 CSV 행 형식 검사 보완은 별도 worktree에서 서브에이전트가 작업한다.

## 남은 검증
전체 완료 후 같은 모집단 키워드/LLM 비교, 사람 정답 대조, 실제 요약 생성·인용 검수, LLM 버전 공개 배포와 PDF 갱신. 현업 검토 시간·구매 의사와 정비 자료 연동·가설 확인은 여전히 미검증 또는 후속 설계다.
