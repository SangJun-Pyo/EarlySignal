# EarlySignal 진행 상태

## 사용자 결정
자동차 회사 고객 안전 담당자의 경보 선택 → 원문 검토 → 요청서 저장. 예선4분, 결선8분 발표·데모+2분질의응답, 검증부록. 주장별 근거·실패·미검증 가정을 공개한다. 50건 AI 시험 후 전체 실행은 별도 결정한다.

## 완료
- 원본 적재·키워드 집계·고정통계·38사례 평가. 실패사례와 주 평가/민감도 구분.
- 키워드42 JSON, 2,142신고·400근거칸·74행결과CSV.
- 요청서 원문 인용·제외·확정·Markdown/JSON다운로드·판단이력. 실제브라우저 R04 확인.
- Python78·웹19테스트/TS/정적빌드, 독립 R01~R03 검수.
- 전체LLM캐시 연결코드와 부분캐시차단. 실제6/7502에서출력보존·거부 확인.

## 진행 중
- AI50건 시험:6건성공,44건실패. 크레딧은작동하나API요청한도429. Chrome키동일확인,조직/프로젝트UI5000RPM·200만TPM과실제50요청한도불일치. 설정변경·추가결제없음. 서버Retry-After대기.
- 동일50건으로재개하도록표본고정·서버대기시간준수수정. 반환usage기준시험비용$0.0053,전체비용/처리량미추정.
- 발표 검토본 완료: 예선 9장 4분, 결선 본문 12장 8분 + 질의응답 2분·부록 4장. 실측과 실제 제품 캡처를 반영하고 25페이지 및 독립 검수를 완료했다.
- 공개 배포: 사용자가 Cloudflare Pages를 선택했다. 기존 GitHub 연결에서 EarlySignal을 선택하고 main / web / npm run build / out 설정까지 준비했다. 최신 코드 반영 후 배포·공개 주소 검증을 진행한다.
