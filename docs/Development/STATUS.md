# EarlySignal 진행 상태

## 사용자 결정
자동차 회사 고객 안전 담당자의 경보 선택 → 원문 검토 → 요청서 저장. 예선4분, 결선8분 발표·데모+2분질의응답, 검증부록. 주장별 근거·실패·미검증 가정을 공개한다. 50건 비용 보고 후 제공된 $50 크레딧으로 전체 실행을 승인했다. 사람 검수는 도메인 지식·공모전 시간 제약으로 당일 미완료를 기록하고 후속 전문가 검수로 이관한다.

## 완료
- 원본 적재·키워드 집계·고정 통계·38사례 평가. 실패 사례와 주 평가/민감도를 구분했다.
- 키워드42 JSON, 2,142신고·400근거칸·74행 결과CSV.
- [공개 Cloudflare 제품](https://earlysignal.pages.dev/)에서 원문 인용·제외, 요청서 저장·Markdown/JSON 다운로드·이력 유지 확인. 공개42 JSON이 검수본과 일치했다.
- 최신 LLM 검수본에서 Python224·웹23 테스트 및 정적 빌드. 라벨 인용 선택과 상황 요약은 별도 에이전트가 검수했다.
- 고정50건 API 출력 검사 완료. 6→36→50건 과정의 요청 제한과 인용 실패를 보존했다. 반환 사용량 누적 추정 $0.0593988. 분류 정확도는 아직 미측정이다.
- 중간 발표 검토본: 예선 본문12장 4분+부록7장, 결선 본문12장 8분+Q&A2분·부록10장. 총41페이지 렌더·독립 검수. 월별 집계와 포아송 본문2장, 다른 통계·현재 LLM 방식·미구현 검색·가설 확인 설계 포함.
- 개발50건과 겹치지 않는 독립 사람검수30건 자료를 준비해 사용자에게 전달했다. 예측은 가리고 정답은 사람이 입력한다.

## 진행 중
- 전체7,502건 분류·출력 검사와 동일 모집단 비교를 완료했다. 공개 제품은 아직 키워드이며 LLM 검수본은 web/public/data로 내보냈다. 실제18경보의 첫 요약 실패와 구조화 후보의 의미 과장을 기록하고, 사용자 선택에 따라 신고별 기존 AI 요약 인용으로 보완했다. 16/18개가 출처·형식 검사를 통과했고 실패2개는 요약 없이 남긴다. 고정50 시험은 보존하고 전체 배치는 `data/results/llm_batch.json`에 보고한다.
- 사람30건 검수는 사용자 요청으로 중단했다. 자료 준비만 완료했으며 정답 0건·분류 정확도 미측정이다. 미완성 평가 구현은 통합하지 않는다(ADR-020, S23, 이슈 #7).
- GitHub 이슈#1 / 기능 브랜치 / PR#4로 통합을 추적한다. CI와 CSV 검사 보완은 독립 검수 후 병합했다. 이슈#11의 검증 출처 표시, 이슈#12의 실제 요약 인용을 별도 작업으로 추적한다.

## 남은 검증
LLM 최종 요약·비용 독립 검수, 공개 배포와 브라우저 검증, 실제 LLM 화면과 통계로 PDF 갱신. 사람 정답 대조는 당일 범위에서 제외하고 전문가 검수를 후속으로 남긴다. 현업 검토 시간·구매 의사와 정비 자료 연동·가설 확인은 여전히 미검증 또는 후속 설계다.
