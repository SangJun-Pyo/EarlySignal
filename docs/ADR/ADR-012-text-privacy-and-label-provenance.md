# ADR-012: 자유서술 식별정보와 라벨 출처를 별도로 검사한다

- 상태: 채택 (ADR-008 보완)
- 날짜: 2026-10-09

## 결정
구조화된 금지 필드를 제외하는 것에 더해, LLM 송신·인용 캐시·웹 내보내기에 사용되는 자유서술에서 이메일·전화·VIN·주소와 명시적인 이름 문구를 가린다. 공개 발췌문은 최대 520자이며 민감 패턴이 있던 문장은 통째로 생략한다. 원본과 작업 DB는 gitignore 안에 둔다. 정규식으로 모든 사람 이름을 찾아낸다고 주장하지 않으며 공개 전 별도 검수를 한다.

API 라벨 캐시는 모델·프롬프트·정제 원문 해시를 보관한다. 같은 신고라도 입력이나 모델이 바뀌면 기존 캐시를 재사용하지 않는다. 인용문은 실제 송신 원문의 부분 문자열이어야 한다. LLM이 없는 신고는 키워드 분류라고 표시하고, 키워드 문장을 AI 요약으로 표시하지 않는다.

## 절충
문장 생략으로 근거 일부가 보이지 않을 수 있다. 원문 번호를 유지해 근거를 추적한다. 비식별 처리의 완전성과 현업 사용 가능성은 별도 검증 대상이다.
