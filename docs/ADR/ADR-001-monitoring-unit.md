# ADR-001: 감시 단위는 브랜드+모델(연식 통합)

- 상태: 제안됨→채택(10/8 사전 조사)
- 날짜: 2026-10-08 (사전 작업)

## 배경
NHTSA 신고는 연식까지 있지만 연식 단위로 나누면 월 건수가 0~2건이라 통계적 변화를 볼 수 없다. 조사 파일의 대상 연식을 감시 단위로 쓰면 정답지(조사 범위)를 탐지에 흘리는 셈이 된다.

## 결정
감시 단위 `grp = MAKE|MODEL` (대문자, trim). 연식은 표시용 정보로만 쓴다.

## 결과와 트레이드오프
- 장점: 건수가 충분해 기준선이 안정적, 조사 정보 누설 없음
- 단점: 특정 연식에만 있는 결함은 희석될 수 있음 → 다음 단계에서 연식 그룹 드릴다운
