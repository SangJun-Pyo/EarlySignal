# ADR-002: 시간 기준은 NHTSA 접수일(LDATE), 판단 시점 이후 정보는 쓰지 않는다

- 상태: 채택
- 날짜: 2026-10-08 (사전 작업)

## 배경
사고일(FAILDATE)은 접수일보다 훨씬 이전일 수 있어, 사고일로 월 집계를 하면 그 달 말에는 알 수 없던 신고가 섞인다. 부품 분류(COMPDESC)는 NHTSA가 사후 수정할 수 있다. 조사 파일의 SUMMARY/CDATE/CAMPNO는 결과(정답지)다.

## 결정
- 월 집계 기준 = LDATE. 월 t의 경보는 t월 말까지 접수된 신고로만 계산하고, 확인 가능일은 t+1월 1일.
- COMPDESC는 탐지 입력 금지(평가용), 조사 결과 필드는 탐지 코드에서 읽지 않는다.
- `tests/test_lookahead.py`로 보증: cut-off에서 잘라 다시 계산해도 그 이전 경보가 같아야 한다.
- 운영 화면(콘솔)은 기준일까지의 실제 값만 그린다. 기준일 이후는 실제 값이 아니라 기준일까지의 데이터로 계산한 **전망 띠(평소 범위, 추세 연장)**(ADR-007)로만 표시한다. 막는 것은 미래 '데이터'이고, 미래 '전망'은 보여준다.

## 결과와 트레이드오프
- 백테스트 결과를 '사후 지식 없이 얻은 것'으로 주장할 수 있다.
- 사후 확인(실제 이후 값, NHTSA 조사 개시)은 '사례 재생' 화면에서만 보여준다.
