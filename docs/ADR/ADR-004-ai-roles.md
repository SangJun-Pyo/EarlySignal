# ADR-004: AI 역할 분담: LLM=측정, 통계=판단, 사람=결정

> **2026-10-09 정정·후속 결정:** 아래의 “일치 60%”는 10/8 시제품 기록이다. 두 방법의 불일치만으로 키워드 정확도가 낮거나 LLM이 정확하다고 판단할 수 없다. 현재 전체 7,502건의 일치는 3,793건이고 사람 정답 정확도는 미측정이다([R06](../Reviews/R06-full-llm-audit.md)). 브리프는 새 서술 대신 제공된 ID 선택·기존 AI 요약 복사로 대체했다([ADR-024](ADR-024-source-summary-selection.md)). 아래 원문은 결정 경위로 보존한다.

- 상태: 채택
- 날짜: 2026-10-08 (사전 작업)

## 배경
LLM이 경보 여부를 직접 판단하면 재현성이 없고, 같은 데이터에 다른 결과가 나올 수 있으며 근거를 검증하기 어렵다. 반면 신고 문장은 표현이 제각각이라 키워드로는 라벨 정확도가 낮다(10/8 표본 60건 일치 60%).

## 결정
- LLM: 신고 원문 → 정해진 enum 라벨·위험 요소·심각도·한국어 요약(Structured Outputs, temperature 0, 캐시)
- 통계: 라벨 시계열에서 경보 판단(ADR-003)
- LLM 브리프: 제공된 근거 신고만으로 요약, 모든 주장에 #ODINO, 원인·결함 단정 금지
- 사람: 조사 착수/보류/기각 결정, 결정 이력 저장
- RAG처럼 LLM이 답을 내는 구조가 아님을 화면·발표에 명시

## 결과와 트레이드오프
- LLM 오분류가 곧바로 경보가 되지 않는다(집계·통계를 거침)
- 키워드 라벨을 기준선으로 남겨 LLM 효과를 비교 가능하게 한다
