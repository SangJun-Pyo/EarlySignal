# ADR-010: 개발·독립 검수·발표를 병행하고 근거로 통합한다

- 상태: 채택 (사용자 승인)
- 날짜: 2026-10-09

## 결정
사용자는 Astra가 전체 지휘를 맡고 난이도에 맞게 서브에이전트를 배정하며, 작성자와 별도의 검수를 요구했다. 파이프라인 구현은 Sol high, 방법론 검수는 주 에이전트 모델을 상속한 별도 에이전트, 발표 제작은 Sol high에 배정한다. 주 에이전트는 의사결정·계약·통합·커밋을 맡는다. 각 에이전트는 소유 파일을 나누며 공유 저장소에서 임의로 커밋하지 않는다.

기존 순차 Step 절차는 의존성 있는 구현에 유지한다. 독립적인 검수·발표 준비와 사용자 질문은 동시에 진행한다. 사용자 승인: 핵심 제품 흐름을 유지하고 주장별 근거·실패·미검증 가정 및 Codex 검수 기록을 보완한다.

발표는 4분 예선용과 결선 8분 발표·데모 + 2분 질의응답용 두 벌로 만든다. 결선 세부 검증은 시간 외 부록으로 둔다(사용자 확인). 같은 증거 목록을 사용하고 세부 수준을 달리한다. API 라벨은 먼저 50건만 실행하며, 측정 결과를 본 사용자가 전체 실행 여부를 결정한다.

## 근거 기록
사전 결과, 오늘 실행 결과, 합성 테스트, 사람 검수, 현업 검증을 구분한다. 모델 간 일치율을 정확도로 해석하지 않는다. 사람 검수 칸은 실제 사람이 판단하기 전까지 비워 둔다. 검수 의견 → 수정 → 재실행 → 통합 커밋 경로를 `docs/Reviews/`와 세션 로그에 남긴다.
