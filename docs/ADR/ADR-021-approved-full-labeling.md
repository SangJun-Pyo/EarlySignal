# ADR-021: 승인된 전체 분류를 실행하고 시험 결과와 분리한다

- 상태: 채택
- 날짜: 2026-10-09
- 관련: ADR-013, ADR-014, ADR-018, ADR-020

## 배경과 사용자 결정

고정 50건의 출력 검사를 마치고 비용을 보고했다. 사용자는 제공받은 $50 크레딧을 사용해 전체 실행을 진행하라고 답했다. 총괄은 전체 7,502건 분류와 데모 경보 요약에 대한 승인으로 이해하고, $50 범위에서 사용량을 관리한다고 전달했다. 별도의 $15 재승인을 받지 않는다.

## 결정

- 기존 성공 50건을 유지한 채 같은 정렬의 전체 7,502건을 처리한다. 모델·분류 프롬프트·통계 규칙은 바꾸지 않고 인용 실패에는 ADR-018의 원문 후보 선택을 적용한다.
- 고정 50건 시험 보고서는 보존한다. 50건보다 큰 실행은 별도 `llm_batch.json`에 보고하고 모든 실행의 사용량 원장은 이어 쓴다.
- 전체 실행은 중간 성공을 즉시 저장하고 API 제한·quota·서버 대기 시간을 따른다. 반환 사용량과 실패를 확인하며, 계정별 실제 청구가 추정과 다를 수 있음을 유지한다.
- 개인정보 필드와 키는 보고서·공개 파일에 쓰지 않는다. 요청 제한을 확인할 때에도 허용된 limit/remaining/reset 헤더의 수치만 읽는다.
- 전체 현재 캐시가 완성된 경우에만 LLM export를 생성한다. 키워드 38사례 주 검증은 그대로 유지하고 같은 데모 신고의 키워드/LLM 차이를 별도 비교한다.
- 실제 경보 요약은 완료 LLM export를 대상으로 생성·검증한다. 실패한 요약은 빈 상태로 남기고 원문 검토 흐름을 유지한다.
- 전체 분류 완료와 분류 정확도 입증을 구분한다. 개발에 쓰지 않은 사람 검수 표본은 ADR-020에 따라 준비하며 정답은 사람이 입력하기 전까지 비워 둔다.
- 사이트·두 PDF·비용 기록은 실제 완료 결과로 갱신하고 재검수한다. 부분 진행을 전체 완료로 발표하지 않는다.
