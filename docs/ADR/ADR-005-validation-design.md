# ADR-005: 검증 설계: 기계적 사례 선정, dev/holdout, 대조군, 12개월 선행 창

- 상태: 채택
- 날짜: 2026-10-08 (사전 작업)

## 배경
잘 맞는 사례만 고르면 결과를 부풀릴 수 있다. 개발에 쓴 사례로 성능을 말하면 과적합을 숨긴다. 선행 기간을 넓게 잡으면 우연한 옛 경보로 선행 일수가 부풀려진다(10/8 36개월 창에서 1,000일대 선행이 나옴).

## 결정
- 사례: RESEARCH §3 기준을 만족하는 리콜 연계 예비조사 전부(38건), target 카테고리는 조사 제목에서 기계적으로 지정
- dev/holdout 무작위 반반(seed 42), 규칙은 dev로만 선택
- 대조군: 같은 제조사, 신고량이 비슷하고 해당 기간 조사가 없던 모델
- 주 지표: 조사 전 12개월 안 target 경보 발생 비율, 사례 vs 대조
- 놓친 사례를 결과에 그대로 남긴다

## 결과와 트레이드오프
- 정직한 숫자(holdout 37% vs 6%)를 얻는 대신 '대부분 잡는다'는 주장은 할 수 없다
- 알려진 약점: 일부 대조군 신고량이 매우 적음 → 당일 개선 후보(SPEC §6)
