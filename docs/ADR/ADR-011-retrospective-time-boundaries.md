# ADR-011: 접수일 기준 과거 재현의 범위와 월 확정 시점

- 상태: 채택 (정확성 보완)
- 날짜: 2026-10-09
- 관련: ADR-002, ADR-005, 독립 검수 R01

## 배경
월 초 날짜는 집계 키일 뿐 그달 신고가 모두 알려진 날짜가 아니다. 현재 받은 NHTSA 파일의 LDATE로 과거를 재현해도 당시 파일의 공개 상태·필드 변경 이력까지 복원할 수 없다. 공식 [CMPL 필드 정의](https://static.nhtsa.gov/odi/ffdd/cmpl/CMPL.txt)는 LDATE를 접수일, DATEA를 파일 추가일로 구분하며 과거 차량 분류 수정 가능성을 안내한다.

## 결정
- 월 m의 집계 확정 시점은 다음 달 1일이다. 월 중간 cut-off에서 완성된 월의 경보만 비교한다.
- 탐지 입력은 기존처럼 LDATE를 사용한다. 조사 이후 결과나 부품 분류를 탐지 입력에 넣지 않는다.
- 선행 일수는 접수일 기준 회고적 분석이다. 당시 실제 서비스가 작동했다거나 실제 조사를 앞당겼다고 주장하지 않는다.
- 현재 파일에 대한 미래 접수 차단 테스트와 당시 데이터 가용성은 구분한다. DATEA 기준 민감도 분석과 당시 snapshot 검증은 별도의 미검증 항목이다.
- 운영 화면에서는 미래 조사 결과를 숨기고, 사후 검증 영역에서만 비교한다.
- 사전 명세의 평가 창은 **접수월 기준**으로 보존한다: m ≥ odate−12개월, m < odate−1개월. 선행 일수는 available=다음달 1일로 계산한다. available에 같은 창을 적용한 값은 별도 민감도 분석이며 주 지표와 섞지 않는다. 검수 중 available 창으로 통일하자는 제안을 재검토해, 원형 명세 보존이 더 적절함을 독립 검수자와 확인했다.
- late 평가에서도 `available <= odate+6개월`인 완성된 월만 첫 경보 후보로 사용한다. 원래 적재 범위의 마지막 부분월을 완성월로 간주하지 않는다. 이 수정은 원래 범위와 임계값을 유지하며 primary/early에는 영향을 주지 않는다.

## 결과
자료의 ‘그날 알 수 있었던 것’은 ‘접수일 기준 재현에서 그달까지의 신고’로 명확히 한다. 미래 정보 차단 테스트가 데이터 수정이나 모델 사전학습의 과거 지식을 배제한다는 의미는 아니다.
