# ADR-014: 시험 표본은 재개해도 고정하고 서버 대기 시간을 지킨다

- 상태: 채택
- 날짜: 2026-10-09

## 배경
사용자는 50건 시험 후 전체 실행을 결정하기로 했다. 크레딧 반영 후 시험에서 6건이 검증을 통과했고 44건은 실패했다. 후속 진단은 잔액 오류가 아닌 `rate_limit_exceeded`였으며 요청 잔여 0, `Retry-After: 1728`을 반환했다. 기존 짧은 재시도는 이 대기 시간을 반영하지 못했다. 또한 캐시를 제외한 뒤 limit을 적용하면 재실행 때 승인된 표본 밖 신고까지 추가될 수 있었다.

## 결정
- `--limit 50`은 seed42 해시 순서의 고정된 첫 50건을 뜻한다. 이 대상에서 성공 캐시를 제외하고 미완료 건만 재개한다. 전체 대상 확대는 사용자 승인 이후에만 한다.
- 유효한 Retry-After를 우선한다. 최대 60초 안의 대기는 공유 대기 시간으로 적용하며, 더 긴 대기는 요청을 보류하고 남은 작업을 멈춘다. 재시도 횟수도 제한한다.
- 긴 대기 정보는 로컬 비공개 상태에 남겨 같은 키·모델의 재실행이 서버 안내보다 일찍 호출하지 못하도록 한다. 키 원문과 응답 본문은 기록하지 않는다.
- 성공 캐시, 실패, 반환된 토큰 사용량, 대기 사유를 분리한다. 미완료 시험을 전체 처리량·정확도 근거로 사용하지 않는다.

## 검증
유료 호출 없는 테스트로 고정 표본 재개, 긴 대기 중지, 후속 실행 차단, 짧은 대기 및 기존 quota 중지를 검사한다. 공식 근거: https://developers.openai.com/api/docs/guides/rate-limits (2026-10-09 확인).
