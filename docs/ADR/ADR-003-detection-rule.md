# ADR-003: 탐지 규칙: 직전 12개월 포아송 기준선, p<0.001 그리고 3건 이상

- 상태: 채택(dev 사례로 선택)
- 날짜: 2026-10-08 (사전 작업)

## 배경
판매 대수(노출량) 데이터가 없어 절대 건수 비교는 의미가 약하다. 각 시계열을 자기 과거와 비교해야 한다. 후보는 (a) 포아송 건수 검정, (b) 그룹 내 비율 이항 검정.

## 결정
- 기준선 λ = 직전 12개월(당월 제외) 평균, 이력 6개월 미만이면 판단 안 함, λ 바닥 0.5
- 경보 = P(X ≥ n | Poisson(λ)) < 0.001 그리고 n ≥ 3
- 10/8 dev 결과: 포아송 8/19 vs 대조 0/19, 비율 검정 7/19 vs 0/19 → 포아송 채택. holdout에는 고정 적용.

## 결과와 트레이드오프
- 다중 검정으로 우연한 경보가 생길 수 있음 → alpha를 작게, 최소 건수 3, 대조군 경보 수로 검토 업무량 공개
- 급성 결함(신고 1~2건)은 못 잡음 → 고위험 단건 알림은 다음 단계
