# ADR-018: 인용 검증 실패는 텍스트 없이 구분하고 고정 표본 안에서 진단한다

- 상태: 채택
- 날짜: 2026-10-09
- 관련: SPEC Step 7, ADR-012, ADR-014

## 배경
`quote_mismatch`는 빈 인용, 송신 원문에 없는 인용, 200자 초과를 구분하지 않았다. 검증에 실패한 응답 본문은 저장하지 않았으므로 과거 실패 원인을 사후에 판별할 수 없다. 원인 확인 없이 원문 일치 조건을 완화하지 않는다.

후속 고정 표본 진단에서 #11222309의 응답 인용은 165자였으나 최장 연속 원문 일치는 75자(45.45%)였다. 대소문자·공백·스마트 따옴표를 정규화해도 같았다. 전체 인용의 결정적 원문 대응이 없으므로 대소문자 변경·유사 문자열·일부 일치에 근거한 자동 복구를 하지 않는다.

## 결정
- 검증 규칙과 프롬프트·스키마·모델·입력 기반 캐시 키를 유지한다. 200자를 넘는 원문 인용도 아직 거부한다. 무조건 앞 200자를 자르면 증상을 설명하는 부분이 사라질 수 있다.
- 인용 실패 시 인용 길이, 비어 있는지, 송신 원문에 정확히 포함되는지, 200자 초과 여부, 공백과 스마트 따옴표만 정규화했을 때 포함되는지의 숫자·불리언을 기록한다. 대소문자만 무시한 일치, 공백·따옴표·대소문자를 함께 정규화한 일치, 정규화 전후 최장 연속 일치 길이와 인용 길이 대비 비율도 진단한다. 정규화 일치나 부분 일치 비율은 진단에만 사용하며 성공 판정에는 사용하지 않는다. 단어, 문장 부호를 일반적으로 바꾸거나 의미를 추측하지 않는다.
- 시도별 진단은 gitignore 대상인 `data/labels/llm_quote_diagnostics.jsonl`에 즉시 저장한다. 실패 기록에도 같은 비텍스트 진단을 붙이고 결과 보고서에는 원인별 건수만 적는다. 실패 원문, 미검증 모델 출력, 비밀값은 저장하지 않는다.
- 선택적 `max_new_rows`는 고정 seed42 표본의 미완료 작업 중 이번에 호출할 건수만 제한한다. 원래 cohort와 재개 대상은 유지한다. `max_attempts=1`과 함께 사용하면 1건·1회 진단이 가능하고 사용량 원장을 그대로 잇는다.
- 과거 진단 부재를 0건으로 해석하지 않는다. 새 진단 통계는 해당 실행에서 관측한 시도만 나타낸다. 자동 인용 수리는 실제 실패 원인을 확인한 후 별도 결정한다.

## 후속 결정: 원문 후보 번호만 재선택
- 선택적 `quote_selection_fallback`으로 인용 실패 시 같은 신고의 추가 모델 호출을 최대 1회 허용한다. 현재 승인 범위는 여전히 같은 seed42 50건이며 7,502건 호출은 승인되지 않았다.
- 첫 응답의 분류·위험 플래그·심각도·요약은 바꾸지 않는다. 해당 필드의 스키마·길이·민감정보 검사를 먼저 통과해야 한다. 후속 모델은 송신 원문에서 추출한 최대 200자 연속 구간의 후보 ID만 strict enum으로 고른다. 지지하는 구간이 없으면 `-1`로 거부할 수 있다.
- 후보는 짧은 문장·절 경계와 긴 구간의 겹치는 창으로 구성한다. 코드는 선택된 시작·끝 위치로 원문을 잘라 인용을 만들고 기존 exact substring·길이·민감정보 검사를 다시 적용한다. 후보가 없거나 ID가 잘못되면 실패한다. 문맥이 후보 경계에서 잘릴 수 있고 원문 일치가 라벨의 의미상 정확성을 보장하지 않으므로 사람 검수를 유지한다.
- 첫 라벨 생성 프롬프트와 cache key는 유지하여 이미 검증된 36건을 보존한다. 후속 선택은 `source-span-v1` 정책, 실제 선택 프롬프트·입력 해시, 모델, 후보 hash, 선택 offset으로 성공 기록에 명시한다. 추가 호출의 usage는 동일 cache key에 `stage=quote_selection` 및 별도 prompt/input hash로 기록한다. 기존 라벨 생성의 출처와 후속 선택 출처를 섞지 않는다.
- 후속 호출도 기존 API 오류·quota·Retry-After·연결 오류 처리와 중단 경계를 따른다. 후속 사용량도 성공 여부와 관계없이 즉시 원장에 추가한다. 미검증 원응답을 파일에 저장하지 않는다.

## 검증
유료 호출 없는 테스트로 빈 인용·과도한 길이·정규화 일치·조작된 문장 거부, 진단 파일의 원문 부재, 성공 전 재시도 진단 보존, 제한 실행 후 같은 표본 재개와 사용량 연결을 검사한다.
