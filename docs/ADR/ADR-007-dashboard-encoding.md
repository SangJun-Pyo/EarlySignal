# ADR-007: 대시보드 표현: 순서로 보여주기, 히트맵 색=평소 대비 배수, 기준일 이후는 두 개의 전망 띠, 데이터 연결 현황은 사실대로

- 상태: 채택
- 날짜: 2026-10-08 (사전 작업)

## 배경
원시 건수로 히트맵을 칠하면 많이 팔린 차종이 늘 진하게 보여 이상 신호가 묻힌다. 기준일 이후의 실제 값을 그리면 그날 담당자가 알 수 없던 정보를 보여주게 된다. 연결하지 않은 데이터 소스를 연결된 것처럼 보이면 신뢰를 잃는다.

10/8 밤 시안 검토: KPI·히트맵·차트·AI 근거·결정 폼·연결 현황 등 패널 9개를 한 화면에 같은 무게로 펼친 시안은 눈이 갈 곳이 없고, 가장 강한 장면("NHTSA보다 240일 먼저")이 버튼 뒤에 숨어 있었다. 화면이 안내 띠(①②③)로 스스로를 설명해야 했고, 면책 문구가 곳곳에 있어 자신감이 떨어져 보였다.

## 결정
- **공간이 아니라 순서로 보여준다.** 시간(기준 월 재생) → 신호(칸 클릭) → AI 근거(집계 먼저, 원문 다음) → 사람의 결정(버튼 3개 + 결정 기록) → 절정(사후 확인: 240일·209일 먼저). 첫 화면의 주인공은 넓은 히트맵 하나. 안내 띠 금지, 상황별 한 줄 안내만.
- 면책 문구는 화면 맨 아래 한 줄로 모은다.
- 히트맵 칸 숫자 = 기준 월 접수 건수, **색 = 평소 대비 배수(n/λ) 구간**, **경보 칸 = 주황 채움**, 최근 2개월 경보 = 주황 테두리
- 추이 차트: 기준일까지 실제 막대 + 직전 12개월 평균선 + 기준일 이후 1~3개월 전망 띠 두 개. 둘 다 기준일까지의 데이터로만 계산한다. 실제 이후 값은 그리지 않는다.
  - **평소 범위**(회청색 점선 띠) = 기준일 시점 λ의 Poisson 5~95% 구간. "문제가 없다면 이 정도"
  - **추세 연장(가정)**(주황 점선 띠) = 최근 3개월 평균의 Poisson 5~95% 구간. "지금 수준이 이어진다면 이 정도"
  - 두 띠 사이가 벌어진 만큼이 "지금 확인해야 하는 이유"다. 차트 위에 한 줄: "평소라면 월 a~b건, 이대로면 월 c~d건"
- 미래 데이터와 미래 전망을 구분한다. 금지되는 것은 기준일 이후 **실제 값**(그날 알 수 없던 답)이고, 기준일까지의 데이터로 계산한 전망은 보여준다. 단 "리콜될 것", "결함" 같은 결과 예측 문구는 쓰지 않는다(검증 범위 밖).
- 데이터 연결 현황: NHTSA 소비자 신고=연결됨, AS·보증/MES 생산 이력/부품 LOT·공급사=미연결(다음 단계)로 표시
- KPI·숫자는 전부 파이프라인 출력. 우선순위 가중치처럼 가정이 들어간 값은 '가정' 표시

## 결과와 트레이드오프
- 담당자는 '평소라면'과 '이대로면'을 비교해 판단할 수 있다
- 추세 연장은 검증된 예측이 아니므로 '가정' 라벨을 붙인다. 시간이 남으면 백테스트로 "다음 달 실제가 추세 띠 안에 든 비율"을 계산해 검증 결과 화면에 싣는다(SPEC §6)
- 사후 결과는 대시보드의 '사후 확인' 모드(회색 실제 막대 + NHTSA 조사 개시선 + 리드 일수)와 '사례 재생' 화면(38건 전체)이 맡는다. 사후 확인 모드는 버튼을 눌러야만 열리고 "사후 확인" 라벨을 단다
- 데모 시간이 다섯 번의 클릭으로 채워지고, 각 화면은 단순해진다. 대신 KPI 카드·조사 대기 표 같은 '관제 화면' 요소는 줄어든다
