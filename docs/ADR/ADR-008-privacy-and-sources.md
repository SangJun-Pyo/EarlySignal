# ADR-008: 개인정보 제외와 출처 명시

- 상태: 채택
- 날짜: 2026-10-08 (사전 작업)

## 배경
NHTSA 공개 파일에는 VIN, 도시, 딜러 연락처, 운전자 이름 필드가 있다. 대회 규정은 개인정보·민감정보 포함을 금지한다.

## 결정
- JSON·화면·로그에 VIN, CITY, STATE, DEALER_*, VEHICLE_OPERATOR를 넣지 않는다(계약 테스트로 검사)
- 신고 원문은 키워드 주변 300자 발췌 + LLM 한국어 요약만 노출
- 데이터 출처(NHTSA ODI, 퍼블릭 도메인)와 다운로드 일자를 README·화면 하단에 표시

## 결과와 트레이드오프
- 원문 전체는 데모에서 볼 수 없다(신고 번호로 NHTSA 사이트에서 확인 가능)
