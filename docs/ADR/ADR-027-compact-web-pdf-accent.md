# ADR-027: 소개 화면에 작은 장식 이미지와 PDF 청록 강조를 적용한다

- 상태: 채택 (사용자 승인, 이슈 #37)
- 날짜: 2026-10-09
- 관련: SPEC Step9, ADR-022, 데이터 계약 v1

## 결정
사용자가 첫 소개 슬로건 오른쪽의 작은 차량 이미지1장과 제목·주요 버튼의 PDF 청록 강조·은은한 빛을 승인했다. 기존 컴팩트 샘플을 참고하며 화면 높이를 크게 늘리지 않는다. 모바일에서는 이미지를 숨긴다. 데이터·통계·문구·데모 CTA 동작·계약은 유지한다.

이미지는 발표 작업 커밋 `7bb7883`의 `docs/presentation/assets/3d/cover.png`에서 만든 기존 `earlysignal-cover-preview.webp`를 재사용한다. 작업 시작 당시 발표 브랜치는 미병합이었고, 이후 발표 통합 main `39e6e07`을 받아 [ADR-026](ADR-026-presentation-3d-art-direction.md)에 연결했다. 이번 웹 변경은 해당 원본이나 PDF를 수정하지 않는다. 이미지는 AI가 만든 장식용 개념 이미지이며 실제 신고 차량·특정 차종·결함·분석 결과를 나타내지 않는다. 빈 alt와 장식 영역 aria-hidden을 사용한다. 새 이미지 생성은 하지 않는다.

기존 청록색을 재사용하고 제목·주요 버튼에만 작은 그림자를 더한다. 전체 패널·차트·요청서 스타일을 확장하지 않는다. 웹 검사·독립 검수 후 총괄이 병합·배포한다.
