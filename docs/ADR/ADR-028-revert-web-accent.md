# ADR-028: 사용자 요청으로 마지막 웹 시각 보완을 되돌린다

- 상태: 채택 (사용자 명시 요청, 이슈 #40)
- 날짜: 2026-10-09
- 관련: SPEC Step9, ADR-022, PR #38

## 결정
사용자가 방금 적용한 웹 디자인을 원하지 않아 “최종 커밋만 revert하고 최신 로그 ZIP”을 요청했다. 마지막 main merge `a9ffba8e92eb93ff9bd872317254ba4c0a1c8ecf`만 `git revert -m 1`로 되돌린다. 직전 발표 통합 `39e6e0739a428c6245030a22462f8ce1ff388fab`은 보존한다.

웹 전체를 직전 버전과 동일하게 복원하며 차량 장식과 제목·주요 버튼의 추가 강조를 제거한다. PDF·통계·공개 데이터·다른 기능은 바꾸지 않는다. 되돌림은 사용자 시각 선호에 따른 결정이며 검증 실패나 데이터 문제로 설명하지 않는다. 이미 작성한 ADR027/S40은 되돌림 대상에 포함되므로 파일을 다시 복원하지 않고 원래 커밋 링크로 역사를 연결한다. 최신 ZIP과 공개 배포 확인은 총괄·별도 담당자가 진행한다.
