# ADR-026: 발표 장식 이미지는 근거와 구분하고 기존 검수본을 보존한다

- 상태: 채택
- 날짜: 2026-10-09
- 관련: 사용자 Truve 레퍼런스 요청, SPEC §1 발표, ADR-009·025, S38

## 결정

- Truve의 남색 표지·마무리와 투명 유리 소재 3D 장면을 참고한다. EarlySignal의 남색·청록색과 기존 9장 본문 서사는 유지한다.
- 표지, 문제 설명, 역할 분담, 마무리에 EarlySignal 전용 생성 이미지를 넣는다. 차량은 특정 제조사·모델이 아닌 개념 이미지이며 사고 사진·실제 장비·구현 기능으로 제시하지 않는다.
- 실제 통계 그림·제품 캡처·숫자·공식 사건 날짜·한계 문구·근거 참조는 보존한다. 장식 때문에 근거를 지우거나 미구현 기능을 추가하지 않는다.
- 기존 ReportLab 편집 원본을 재사용하는 별도 장식 빌더로 `-3d.pdf` 두 파일을 만든다. 이전 최종 PDF·DRAFT·storyboard·qa.json의 검수 스냅샷은 덮어쓰지 않는다.
- 예선 18장·결선 21장, 본문 각각 9장, 240/480초 배분과 120초 질의응답을 유지한다. 시간은 여전히 배분안이다.
- 장식 이미지의 생성 도구·프롬프트·파일 해시와 새 PDF의 검수 결과는 별도로 기록한다. 실제 출력과 비교해 텍스트·숫자 누락 및 잘림을 확인한다.

## 범위

발표 시각 개선만 수행한다. 파이프라인·공개 JSON·웹·데이터 계약·통계 규칙을 바꾸지 않는다. 통합은 독립 검수 후 별도 PR로 진행한다.

## 2026-10-09 후속 요청: 이슈 #35 부록과 발화 대본

- 사용자가 모델연도 후속 과제인 이슈 #35를 부록에 다루고 발표 스크립트를 만들도록 요청했다. 제품의 연식별 필터·독립 경보 구현 요청으로 확대하지 않는다.
- 기존 3D판 18/21쪽은 보존하고, 각 파일 끝에 현재 연식 분포와 후속 검증 계획 두 쪽을 추가한 `-3d-v2.pdf`를 만든다. 새 구성은 예선20쪽·결선23쪽이며 본문9쪽과 발표 배분240/480초는 그대로다.
- 데모 근거17건의 모델연도는 공개 JSON의 실제 신고를 다시 합산한다. 신고 건수와 위험률·원인·세대별 성능을 구분한다. 확인하지 않은 풀체인지 경계나 차종 세대는 그림·텍스트에 만들지 않는다.
- 대본에는 읽을 문장과 조작 지시를 나누고, 부록은 질의응답용으로 둔다. 실제 리허설을 했다고 쓰지 않는다. 기존 S38/R11/QA는 당시 검수본으로 보존하고 새 결과를 S39에 기록한다.
