# ADR-013: 완성된 LLM 캐시만 제품 집계에 연결한다

> **2026-10-09 후속 상태:** 아래 50건 승인 범위는 당시 결정이다. 이후 [ADR-021](ADR-021-approved-full-labeling.md)에 따라 전체 7,502건을 승인·완료했다([R06](../Reviews/R06-full-llm-audit.md)). 전체 현재 캐시 검사 원칙과 키워드 38사례 주 검증 유지 원칙은 그대로 적용한다.

- 상태: 채택 (기존 사용자 비용 승인 경계를 구현)
- 날짜: 2026-10-09
- 관련: ADR-004, ADR-010, ADR-012, SPEC Step 7·8

## 결정
50건 시험은 모델·비용 검증용이다. 전체 demo의 현재 원문·모델·프롬프트·스키마 해시와 맞는 성공 캐시가 한 건씩 모두 있을 때만 LLM 집계와 내보내기를 허용한다. 가져오기·집계·내보내기는 API를 호출하지 않는다. 미완성 또는 오래된 캐시는 기존 키워드 파일을 바꾸기 전에 실패한다. 공개 요약은 알려진 식별값과 표준 패턴을 다시 검사한다.

38개 사례·36개 대조의 주 검증 지표와 CSV는 키워드 기준선을 유지한다. 데모의 LLM은 더 짧은 관측 기간이므로 이 결과로 38건 검증을 덮어쓰지 않는다. 같은 demo 모집단에서 키워드와 LLM을 재집계한 비교는 별도 결과 파일에 쓰며, 세 대표 사례의 LLM 상세에는 관측 범위를 명시한다. LLM 내보내기는 캐시를 다시 검사하고 같은 입력으로 탐지를 재계산해 오래된 DB 집계를 재사용하지 않는다.

LLM 요약 캐시는 실제 모델 실행으로 생성하고 검증된 경우에만 사용한다. 라벨의 한국어 요약과 여러 신고를 종합한 상황 요약은 별개다. 상황 요약이 없으면 briefs는 빈 상태로 내보낸다.

## 승인 경계
현재 승인 범위는 50건 시험이다. 이 ADR은 전체 API 호출 승인이 아니다. 본 실행은 비용 보고 후 사용자가 결정한다.
