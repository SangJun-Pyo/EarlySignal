- 대상: `brief.py`, `cli.py`, `export_llm.py`, 관련 테스트, ADR-015
- 실제 API 호출: 없음. 키 열람: 없음.

## 발견한 문제와 수정

| 문제 | 재현과 영향 | 수정 및 독립 재검수 |
|---|---|---|
| 공백 없는 다음 문장이 인용 검사를 우회 | `…(#1000).주차 중 …`의 두 번째 문장에 인용이 없어도 허용 | 문장부호 경계를 보강하고 미인용 문장을 `uncited_narrative`로 거부 |
| 복합 한글 수량을 놓침 | 근거에 없는 `열한 명`, `십 명`, `한 사람`을 허용 | 수량 검사를 보강하고 `unsupported_narrative_number`로 거부 |
| 심각도를 불리언으로 정렬 | 같은 위험 플래그의 12건에서 더 높은 실제 심각도 신고가 상위 10건에 들지 못함 | 실제 심각도 값으로 정렬; 재현 신고가 첫 번째로 선택됨 |

기존 캐시와 export에서도 같은 검증을 다시 수행한다. 정규식과 스키마 검사는 모든 의미 왜곡이나 식별정보를 증명하지 못하며 담당자의 원문 대조는 남는다.

## 확인한 경계

- 완료 LLM export의 스키마·파일 집합·모든 SHA256·콘솔 건수·라벨 출처를 확인한다.
- 부분 LLM 캐시를 전체 데이터로 연결하지 않는다. export에는 유료 호출이 없다.
- 상황 요약에는 같은 근거 칸의 최대 10건, 요약·번호·상황 플래그와 통계만 입력한다. 사후 결과는 입력하지 않는다.
- quota와 영구 API 오류는 전체 중지한다. 긴 서버 대기는 보류하고 반환된 실패 응답의 사용량도 비용에 포함한다.
- 입력·모델·프롬프트·선택 근거·식별값 검사에 연결한 캐시를 재검증한다. 사용량을 알 수 없으면 0으로 추정하지 않는다.
