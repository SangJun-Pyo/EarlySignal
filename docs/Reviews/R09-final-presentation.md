## 직접 수행한 검사

- 확정 파일을 독립적으로 Poppler에서 1280×720 PNG로 전 페이지 재렌더하고, 예선 1~18·결선 1~21의 총 39페이지를 빠짐없이 시각 검사했다. 글자·차트·표·화살표·캡처·각주·페이지 번호에서 잘림, 겹침, 빈 페이지, 깨진 글자를 발견하지 않았다.
- `pypdf`로 39페이지의 텍스트·페이지 크기를 읽었다. 대체 문자 0개이고, 실제 추출 문자열과 Regular/SemiBold 폰트 문자 매핑을 대조한 미지원 글리프도 0개다. 화면에 등장하는 E01~E29 근거 ID 모두 근거표에 정의되어 있다.
- storyboard의 본문 순서와 노트를 대조했다. 예선 시간은 25+15+20+60+25+35+25+15+20=240초, 결선은 40+25+45+100+50+65+60+40+55=480초다. 결선 질의응답 120초는 별도이며 부록은 시간 외다. 예선 실제 제품 시연 배분은 60초다.
- 1장은 실제 사건과 슬로건, 3장은 LLM·통계·담당자 역할, 8장은 LLM 변화와 정확도 한계에 집중한다. “고객의 목소리를, 조사의 근거로.”가 표지와 마무리에 이어진다. 미측정 사항을 지우지 않고 앞면 발화의 반복만 줄인 노트와 일치한다.
- 내용 검수 뒤 내부 초안 표기를 발표자료로 바꾸고 표지 사건에 미국을 명시한 최종 PDF 39페이지를 다시 렌더했다. 추출 텍스트 차이는 요청된 표기와 표지 한 문장뿐이다. 표지 외 37페이지 본문 픽셀이 이전 검수본과 같고, 표지 변경도 해당 문장·머리말·태그 영역에 한정됨을 확인했다. 바뀐 표지·머리말·꼬리말의 실제 렌더에서 잘림이 없고 PDF 내부 초안 표기와 글리프 누락은 모두 0개다.

## 수치와 검증 범위

본문 5·6장의 통계 두 장을 유지했다. 공개 LLM 시계열을 직접 합산해 직전 12개월 59건, 평균 59/12=4.9166666667, 당월 17건, 3.4576271186배를 확인했다. 독립 상측 확률 합산은 0.000016130219673942366이며 화면 0.00161%와 일치한다. 당월 제외·접수일·0건 월·다음 달 확인 가능일을 구분한다. 포아송 오른쪽 꼬리 확대에는 별도 세로축이 명시되고, p값이 결함 확률이 아니라는 설명과 “평소보다 이례적인 증가” 해석이 유지된다. 도표 입력 경계 테스트 6개와 그림 근거 파일 6개의 해시도 확인했다.

다음 결과를 서로 다른 검증으로 표현한다.

- 등록 38사례 키워드 백테스트: 개발 사례 9/19·대조 0/19, 검증 사례 7/19·대조 1/17. 모형 적합성·일반 정확도와 구별한다.
- 동일 7,502건의 주 라벨 일치 3,793건(50.56%): 방법 간 일치이며 사람 정답 정확도가 아니다. 같은 4,464칸의 경보 34→39도 개선된 정확도로 해석하지 않는다.
- API 출력 검사 7,502건 및 대표 신고 요약 16/18개: 형식·출처 복사 검사다. 사람 정답 0건·정확도 미측정을 남기고, 사용자 검수 미완료를 AI 정답으로 대체하지 않았다.

현대·기아의 209·240일은 지정 PE19-003·004의 2019-03-29 개시일 대비임을 본문과 부록에서 명시한다. 2018-06-11 청원, 2018-08-21 DP18-003 검토, 앞선 RQ17-003·004가 있어 기관의 최초 인지·조사나 AI 최초 발견을 뜻하지 않는다. 이 핵심 맥락은 [NHTSA DP18-003 종료 문서](https://static.nhtsa.gov/odi/inv/2018/INCLA-DP18003-5116.PDF)와 독립 대조했다. 볼트 키워드 놓침·LLM 23일 늦음도 그대로 남는다.
