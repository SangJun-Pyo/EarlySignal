## 완료와 검증

현재 demo **7,502건**과 성공 캐시 **7,502건**의 고유 신고·캐시 키가 일대일로 맞는다. `load_complete`를 읽기 전용 DB 연결로 실행해 현재 모델·프롬프트·정제 원문 해시·캐시 키와 스키마·원문 부분 문자열·민감정보 검사를 다시 통과했다. 누락·오래된 입력·스키마 위반·인용/민감정보 검사 실패는 각각 **0건**이다. DB 연결은 검수 입력을 읽은 뒤 닫았다.

원문 후보 ID로 인용을 재선택한 **2,443건**은 원문으로 후보를 다시 만들었다. 후보 수·후보 해시·선택 위치·실제 원문 slice·선택 프롬프트 해시·같은 실행의 사용량 연결을 대조했고 각 불일치 **0건**이다. 나머지 **5,059건**은 별도 인용 선택 기록 없이 기존 원문 인용 검증을 통과했다. 재선택은 분류·위험 플래그·요약을 수정하는 정책이 아니며, 문자열 일치가 의미상 정확성을 보장하지 않는다.

마지막 전체 배치는 기존 캐시 **51건**을 재사용해 **7,451건**을 추가했다. 반환 응답 **9,880회**, 인용 선택 **2,429건**, 최종 실패 **0건**, 라벨 재시도 **0회**였다. 인용 선택은 별도 응답·비용으로 계산되므로 응답 수를 신고 수나 재시도 수와 혼동하지 않는다. 앞선 시험·진단의 실패 기록은 비용과 실행 이력에 남아 있으며 마지막 배치 실패 0건으로 과거 실패를 지우지 않았다.

## 비용 대조

비용은 반환된 토큰 사용량에 기록된 모델 요율(입력 $0.40, 캐시 입력 $0.10, 출력 $1.60 / 백만 토큰)을 적용한 추정치다. 청구서 실결제액이나 새 요율 검증 결과가 아니다.

| 구분 | 반환 응답 | 추정 USD |
|---|---:|---:|
| 마지막 전체 배치 | 9,880 | 4.4850100 |
| 앞선 시험·진단·추가 1건 확인 | 116 | 0.0598736 |
| 누적 라벨 실험 | 9,996 | **4.5448836** |

전체 반환 사용량 **9,996개**가 모두 사용량을 포함하며, 입력 **7,804,049토큰**, 출력 **889,540토큰**, 캐시 입력 **0토큰**이다. 정수 토큰과 십진 요율로 재계산한 비용은 각 기록 및 **8개 실행**의 응답 수·비용과 일치했다.

그러나 과거 사용량 **10개**($0.0053076)에 `cache_key`가 없고 현재 성공 키 **6개**에는 연결된 사용량이 없다. 키로 연결된 사용량은 **9,986개**, 현재 성공 키는 **7,496개**다. 따라서 누적 실험 총액과 **정확한 현재 캐시의 1,000건당 비용**은 구별하며, 후자는 `null`·미측정으로 둔다. 누적 금액을 7,502로 나누어 완전한 캐시 단가라고 보고하지 않는다. 사용량 없는 오류 응답이나 계정별 과금 차이는 이 원장만으로 확인할 수 없다.

상황 요약(brief) 생성 사용량은 이 라벨 원장 합계에 포함하지 않았다. 별도 생성·검수 결과가 제공되기 전에는 비용을 0으로 간주하지 않고 **별도 집계 대기**로 표시한다.

## 독립 통계 대조

같은 demo 신고에 대해 접수일 `ldate`의 월과 고유 신고 번호를 사용해 범주별 건수를 별도로 셌다. 각 월의 이전 최대 12개월 평균, 최소 이력 6개월, 평균 하한 0.5, Poisson 상측 확률 `< 0.001`, 건수 `≥ 3`을 스칼라 계산으로 적용했다. 이 계산은 제품의 `aggregate_frame`·`detect_frame`을 호출해 oracle 값을 만드는 방식이 아니다. 이후 제품 재계산 값과 월 건수·평균·확률·경보를 대조했다.

| 동일 demo 비교 | 키워드 | LLM |
|---|---:|---:|
| 검사한 월×차종×범주 셀 | 4,464 | 4,464 |
| 경보 셀 | 34 | 39 |
| 스칼라 oracle과 불일치 | 0 | 0 |

주 범주 일치는 **3,793 / 7,502건**이다. 이는 두 방법의 일치이며 사람 정답 대비 정확도가 아니다. 독립 집계는 export의 `llm_demo_comparison.json`과 일치했다.

대표 사례의 보고된 첫 경보 셀도 독립 집계와 대조하고, 월 완료 후 사용 가능일과 조사 개시일의 날짜 차이를 **5개 경보 결과**에서 계산해 불일치 0건을 확인했다.

| 사례 | 키워드 | LLM |
|---|---|---|
| PE19003 | 209일 먼저 | 209일 먼저 |
| PE19004 | 240일 먼저 | 240일 먼저 |
| PE20016 | 놓침 | 23일 늦음 |

이 비교는 동일 demo의 제한된 관측 창이며 등록된 전체 사례 창을 채우지 않는다. LLM 경보 39개가 키워드 34개보다 많다는 사실은 우월성·정확도 향상의 근거가 아니다. 기존 **38사례 키워드 백테스트**와도 구별한다. Bolt 결과는 여전히 늦은 사례로 남긴다.

## 검수 범위와 한계

- 사람 검수는 사용자 요청으로 취소됐고 사람 정답 검수 건수는 **0건**이다. 키워드·LLM 정확도는 모두 **미측정**이다. 실제 비공개 정답 CSV는 이 검수에서 읽거나 변경하지 않았다.
- 원문·개인정보·개별 사용량 신고 번호는 보고서나 콘솔 출력에 남기지 않았다. 공개 JSON은 합계·검증 상태·파일 SHA256만 담는다.
- 새 API 호출, 키·환경 파일 읽기, DB 쓰기, 제품 코드 수정은 하지 않았다. 지정된 집계 JSON과 이 검수 문서만 추가한다.
- 스키마·원문 인용·알려진 식별값 검사 통과는 완전한 비식별화나 소비자 진술의 사실 확인·의미상 분류 정확성을 보장하지 않는다. 상황 요약 생성·공개 export·실제 배포의 추가 검수는 별도다.
