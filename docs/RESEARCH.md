## 2. 데이터 사실
- NHTSA ODI 신고 파일: UTF-8, 탭 구분, 헤더 없음, 51컬럼. 신고문에 따옴표가 있어 따옴표 해석을 꺼야 행이 깨지지 않는다.
- 2010~2024 신고 파일 3개: 원본 1,301,663행 → 소비자 신고·ODINO 중복 제거 후 932,837건. DuckDB 적재 약 20초.
- `CMPL_TYPE` 실제 값: IVOQ, EVOQ, LETR, SVOQ, CON, VOQ, MIVQ, MAVQ, DP, CAG.
- 조사 파일: 154,401행, 고유 조사 5,349건. 한 조사가 차종·연식별 여러 행. `CAMPNO`로 리콜과 연결.
- 조사 파일의 MAKE/MODEL 표기는 신고 파일과 같아 바로 매칭된다.
- 연식 단위로는 건수가 너무 적어 **브랜드+모델(연식 통합)**을 감시 단위로 정했다. 조사 대상 연식 정보는 탐지에 쓰지 않는다.

## 3. 백테스트 사례 선정 기준 (`data/cases_pool.yaml`)
손으로 고르지 않고 아래 조건을 만족하는 건을 **전부** 넣었다.
1. 조사 종류 PE(예비평가), `CAMPNO` 있음(리콜로 이어짐), 개시일 2014-06 ~ 2024-06
2. 제외: 오토바이·RV·트레일러·타이어·자율주행·특수장비, 대상 모델 7개 이상(다카타급 초대형)
3. 조사 제목+부품명에 키워드 라벨러를 적용해 target 카테고리를 **기계적으로 지정**(사전 등록). 해당 카테고리 없으면 제외
4. 조사 전 36개월 신고 60건 미만이면 제외
5. dev/holdout 무작위 반반(seed 42)
6. 대조군: 같은 제조사, 조사 전 36개월 신고량이 가장 비슷하고, [−36개월, +12개월] 동안 어떤 조사에도 걸리지 않은 모델 1개

결과: 사례 38건(dev 19, holdout 19), 대조군 36개.
알려진 약점: target 기계 지정이 거친 경우가 있다(예: PE18011 "Power tailgate opens unintended" → 전기 계통). 신고량이 매우 적은 대조군이 일부 있다(SMART FORTWO COUPE ELECTRIC, MERCEDES GLE350).

## 4. 파라미터와 정의
- 기준선 직전 12개월 평균, 최소 이력 6개월, λ 바닥 0.5
- 경보: Poisson 꼬리확률 p < 0.001, 해당 월 3건 이상
- 선행 기간: 조사 전 12개월 안의 첫 target 경보 기준. 36개월로 잡았더니 우연한 옛 경보 하나로 선행 기간이 1,000일씩 부풀려져서 12개월로 줄였다.
- 확인 가능일 = 경보 월의 다음 달 1일

## 5. 시제품 결과 (재현 목표값)
| | 조사로 이어진 차종 | 대조 차종 |
|---|---|---|
| dev (규칙 선택에 사용) | 8/19 (42%) | 0/19 (0%) |
| holdout (규칙 고정 후 처음 적용) | 7/19 (37%) | 1/17 (6%) |

- 규칙 선택: dev에서 포아송(8/19, 0/19)이 비율 이항검정(7/19, 0/19)보다 나아 포아송 채택.
- 차종 1개짜리 사례만: 사례 6/20 vs 대조 1/19.
- 미래 정보 차단 테스트: 38개 cut-off 모두 일치.
- 검토 업무량: 조사가 없던 차종 하나당 월 0.08건(모든 증상). 100개 차종 감시 시 월 약 8건.
- 대표 사례: PE19003 현대 비충돌 화재 **209일 먼저**(쏘나타 화재 2018-08 16~17건/평소 6~7건), PE19004 기아 **240일 먼저**(쏘렌토 2018-07). 2018-10에 현대·기아 5개 차종 화재 신고 동시 급증.
- 실패 사례: PE20016 쉐보레 볼트 EV(조사 전 신고 극소수, 급성), PE18008 F-150 안전벨트 프리텐셔너 화재(놓침) 등.

## 6. 라벨 실험 (시제품, Claude로 라벨)
- 무작위 60건 키워드 vs LLM primary 일치 36/60(60%). 키워드 오류 유형: 오타("BREAK FLUID"), 문맥("under the hood"→차체), 고유명사("Takata", "MCU").
- 데모 범위 7,502건 LLM 라벨: 탐지 시점은 키워드와 같았다(209일, 240일). 볼트 EV는 키워드 "조사 이후", LLM "놓침".
- LLM이 더한 것: 키워드에 없던 `engine_failure`가 화재와 같은 시기 급증(쏘렌토 2018-07 32건/평소 11.6, 쏘나타 2018-10 31건/평소 12.3), 근거 신고 한국어 요약, 경보 브리프.
- 당일에는 같은 스키마로 OpenAI 라벨을 다시 만든다(당일 구현).

## 7. 아직 검증하지 못한 가정
