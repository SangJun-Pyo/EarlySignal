# 화면 참고 (DESIGN_REF)

> **역사 기록 · 2026-10-08 화면 시안:** 아래 수치·문구·문서번호·저장일·연결 상태는 당시 시안이며 현재 제품의 구현 근거가 아니다. 현재 화면은 [공개 제품](https://earlysignal.pages.dev/), 명세는 [SPEC](SPEC.md), 값은 [console.json](../web/public/data/console.json)을 따른다.

> 사전 작업(10/8). 참고 시안은 행사 전 AI 도구(Claude)로 만든 클릭 시안이며, 이 문서는 그 화면을 글로 옮긴 것이다. **코드는 포함하지 않는다.** Codex는 이 문서와 `docs/design-ref/*.png` 캡처를 흐름·배치 참고용으로만 쓰고, 화면 코드는 새로 작성한다. 숫자는 시제품 값이므로 당일 `console.json` 값으로 바뀐다. 결정 배경은 ADR-007, ADR-009.

## 공통
- 다크 업무 화면. 바탕 #0b1626, 패널 #10233a, 선 #1e3a57, 글자 #e6eef7, 보조 글자 #8fa3b8, 강조 #22d3ee, 경보 #f5a524, 위험 #f05252, 검증 #60a5fa.
- 요청서 문서만 밝은 종이(#f7f5f0, 글자 #1b1f24). 결과물이 화면에서 분리되어 보이게.
- 폰트 IBM Plex Sans KR, 신고 번호와 원문은 IBM Plex Mono. 숫자 tabular. 본문 14px 이상(프로젝터).
- 버튼·칸은 모두 실제 `<button>`, 최소 높이 44px.
- 상단: 로고 "EarlySignal" + "품질안전팀 작업 공간 · 과거 데이터 재연" / 단계 내비게이션 `신고 원문 | 신호와 근거 | 조사 요청서(초안·확정됨 표시)` + `검증 결과`.
- 하단 한 줄: 데이터 연결(NHTSA 연결됨 / AS·보증·MES·부품 LOT 다음 단계) · "과거 데이터 재연 · 경보는 결함 판정이 아닌 조사 후보 · AI 라벨은 사전 실행 결과". 면책 문구는 여기와 요청서 꼬리말에만.

```
                                          └──────────────────────────────────────────────┘
```
- 경보를 고르기 전 오른쪽에는 "분석 시점을 6월 → 7월 → 8월로 옮겨 보세요…" 안내 한 문단만.
- 제외한 원문 카드는 흐리게, 인용한 카드는 청록 테두리.

- "언제 만들 수 있었나" 카드와 저장된 결과물은 **확정·저장 후에만** 나타난다.
- 연결된 공식 조사가 없는 신호면 "연결된 조사 없음"으로 표시.

## 검증 결과 (패널)
- 제목 "한 사례만 고른 게 아닙니다…". 카드 3개: 개발 사례 8/19 vs 대조 0/19, 홀드아웃 7/19 vs 대조 1/17, 현대 209일·기아 240일. 놓친 사례 문장(볼트 EV).
