## 수치를 읽는 기준

- 주 지표 평가창은 **경보 접수월 기준**이다. 확인 가능일에 같은 창을 적용한 값은 별도 민감도 분석이며 주 지표와 섞지 않는다.
- 선행 일수는 **월 경보 다음 달 1일**과 지정 조사 기록 개시일의 차이다. 현대·기아 209일·240일은 지정 PE19-003·004의 2019-03-29 대비이며 기관 최초 인지·최초 조사·AI 최초 발견을 뜻하지 않는다. 해당 시점에 실제 도구가 운영되었다거나 조사·사고가 실제로 앞당겨졌다는 뜻이 아니다.
- 사전 결과에서 dev 8/19였던 값은 당일 구현에서 9/19다. 볼트는 사전 late였으나 현재 missed다. 사전 수치에 맞추기 위해 임계값이나 키워드를 변경하지 않았다.
- 원본 다운로드 시각은 확인되지 않았다. `meta.data_source.downloaded_at=null`, `observed_local_date=2026-10-09`를 구분한다.
- AI 시험의 50건 성공은 스키마·인용 검사를 통과한 캐시 수다. 사람이 정답을 확인한 50건이나 정확도 100%를 뜻하지 않는다.


## 비용과 실행 이력

라벨 누적 9,996개 반환 응답의 추정 비용은 $4.5448836이다. 마지막 전체 배치 $4.48501과 앞선 시험·진단 $0.0598736을 포함한다. 초기 사용량 10개에는 캐시 키가 없고 현재 성공 키 6개에는 연결 사용량이 없어 검증된 건당 단가는 미측정이다. 요약 실험78응답 $0.0292060을 더한 전체 실험은 $4.5740896이다. 새 요약 선택22응답의 $0.0071512도 이 금액에 포함된다. R08의 십진 검산과 일치한다. 금액은 모델 요율에 따른 반환 사용량 추정이며 실제 청구서가 아니다.

## 외부 기술 정의

- [NIST Poisson distribution](https://www.itl.nist.gov/div898/handbook/eda/section3/eda366j.htm): 이론 분포 정의이며 프로젝트 데이터 적합성의 근거는 아니다.
- [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs): 출력 구조 제약이며 의미 정답을 보장하지 않는다.
- [pgvector 공식 저장소](https://github.com/pgvector/pgvector): 벡터 유사도 검색 기술이며 현재 제품에서 미사용이다.
