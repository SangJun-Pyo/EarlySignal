## 수치를 읽는 기준

- 주 지표 평가창은 **경보 접수월 기준**이다. 확인 가능일에 같은 창을 적용한 값은 별도 민감도 분석이며 주 지표와 섞지 않는다.
- 선행 일수는 **월 경보 다음 달 1일**과 공식 조사 개시일의 차이다. 해당 시점에 실제 도구가 운영되었다거나 조사·사고가 실제로 앞당겨졌다는 뜻이 아니다.
- 사전 결과에서 dev 8/19였던 값은 당일 구현에서 9/19다. 볼트는 사전 late였으나 현재 missed다. 사전 수치에 맞추기 위해 임계값이나 키워드를 변경하지 않았다.
- 원본 다운로드 시각은 확인되지 않았다. `meta.data_source.downloaded_at=null`, `observed_local_date=2026-10-09`를 구분한다.
- AI 시험의 6건 성공은 스키마·인용 검사를 통과한 캐시 수다. 사람이 정답을 확인한 6건이나 정확도 100%를 뜻하지 않는다.

## 일부 AI 시험 비용의 범위

`llm_pilot.json`의 `2026-10-09T01:36:26.583490+00:00` 실행은 응답 10회, 입력 8,349토큰·출력 1,230토큰, 사용량 기반 추정 $0.0053076을 기록했다. 완료 라벨은 6건이며 인용 불일치 시도 4회가 있었다. 이 값은 해당 실행에서 사용량이 반환된 응답만의 추정치이며, 전체 50건 비용·계정 실제 청구액·지속 처리량을 뜻하지 않는다. 현재 PDF 본문에는 이 불완전한 표본으로 계산한 전체 비용과 속도 추정을 싣지 않았다.

## 검수와 수정의 예

요청서 문서번호가 증상 코드 첫 단어만 사용해 `engine_stall`과 `engine_failure`를 구분하지 못했다. 독립 검수에서 이 문제를 발견했고 제조사·모델·전체 증상 코드로 바꿨다. 두 증상에서 서로 다른 번호가 생성되는 테스트를 추가했다. 이는 실제 수정 사례이며 현업 생산성 개선 수치로 바꾸어 말하지 않는다.

## 최종 제출 전

사람 검수, 50건 시험, 전체 실행 승인, 최종 배포 시연, 실제 발표 리허설은 각각 별도 완료 조건이다. 이 중 하나의 성공을 다른 항목의 완료로 대신하지 않는다. 최신 PDF 출처 파일 해시는 `qa.json`에서 확인한다.
