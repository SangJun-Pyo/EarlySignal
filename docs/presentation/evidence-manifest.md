## 수치를 읽는 기준

- 주 지표 평가창은 **경보 접수월 기준**이다. 확인 가능일에 같은 창을 적용한 값은 별도 민감도 분석이며 주 지표와 섞지 않는다.
- 선행 일수는 **월 경보 다음 달 1일**과 공식 조사 개시일의 차이다. 해당 시점에 실제 도구가 운영되었다거나 조사·사고가 실제로 앞당겨졌다는 뜻이 아니다.
- 사전 결과에서 dev 8/19였던 값은 당일 구현에서 9/19다. 볼트는 사전 late였으나 현재 missed다. 사전 수치에 맞추기 위해 임계값이나 키워드를 변경하지 않았다.
- 원본 다운로드 시각은 확인되지 않았다. `meta.data_source.downloaded_at=null`, `observed_local_date=2026-10-09`를 구분한다.
- AI 시험의 50건 성공은 스키마·인용 검사를 통과한 캐시 수다. 사람이 정답을 확인한 50건이나 정확도 100%를 뜻하지 않는다.

## 일부 AI 시험 비용의 범위

`llm_pilot.json`의 `2026-10-09T01:36:26.583490+00:00` 실행은 응답 10회, 입력 8,349토큰·출력 1,230토큰, 사용량 기반 추정 $0.0053076을 기록했다. 완료 라벨은 6건이며 인용 불일치 시도 4회가 있었다. 이 값은 해당 실행에서 사용량이 반환된 응답만의 추정치이며, 전체 50건 비용·계정 실제 청구액·지속 처리량을 뜻하지 않는다. 현재 PDF 본문에는 이 불완전한 표본으로 계산한 전체 비용과 속도 추정을 싣지 않았다.

## 검수와 수정의 예

요청서 문서번호가 증상 코드 첫 단어만 사용해 `engine_stall`과 `engine_failure`를 구분하지 못했다. 독립 검수에서 이 문제를 발견했고 제조사·모델·전체 증상 코드로 바꿨다. 두 증상에서 서로 다른 번호가 생성되는 테스트를 추가했다. 이는 실제 수정 사례이며 현업 생산성 개선 수치로 바꾸어 말하지 않는다.

## 최종 제출 전

사람 검수, 50건 시험, 전체 실행 승인, 최종 배포 시연, 실제 발표 리허설은 각각 별도 완료 조건이다. 이 중 하나의 성공을 다른 항목의 완료로 대신하지 않는다. 최신 PDF 출처 파일 해시는 `qa.json`에서 확인한다.

## 2026-10-09 11시 재개 결과 반영

이전 11:11 KST 재개 실행 `2026-10-09T02:11:30.382010+00:00`은 기존 고정 50건 중 캐시 6건을 재사용하고 30건을 추가 통과해 당시 총 36건이 유효했다. 당시 14건은 인용 검사 실패로 미완료였고, 이후의 완료 결과는 아래에 따로 기록한다. 요청 제한 오류가 해소된 뒤의 상태를 이전 44건 API 실패 상태와 구분한다. 이번 실행은 응답 75회, 입력 64,646·출력 9,530토큰, 사용량 추정 $0.0411064다. 앞 실행 추정 $0.0053076을 합하면 $0.046414지만 실제 계정 청구액·전체 비용·정확도·지속 처리량은 아니다.

## 외부 기술 정의

- [NIST Poisson distribution](https://www.itl.nist.gov/div898/handbook/eda/section3/eda366j.htm): 포아송 이론 분포 정의. 이 프로젝트 데이터의 적합성을 입증하는 자료는 아니다.
- [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs): 출력 구조의 제약. 의미상 정답을 보장하지 않는다.
- [pgvector 공식 저장소](https://github.com/pgvector/pgvector): PostgreSQL에서 벡터 유사도 검색을 지원하는 기술. 현재 EarlySignal에 도입됐다는 근거는 아니다.

## 최신 제출 범위

예선 12장/240초 + 부록 7장, 결선 12장/480초 + Q&A 120초 + 부록 10장. 공개 제품 캡처를 사용하고 모든 페이지를 다시 렌더링했다. PDF와 수치·그림·캡처의 SHA256은 `qa.json`에 기록한다. 실제 시연 타이머 리허설과 장애 대비 녹화는 미완료다.

## 고정 50건 출력 검사 완료 · 정확도와 구분

최신 실행 `2026-10-09T02:32:55.884767+00:00`에서 13건이 추가 통과하고 기존 37건을 재사용해 고정 표본 50건의 API 출력 검사가 완료됐다. 초기 실패 14건은 ADR-018의 `source-span-v1` 방식으로 같은 원문 후보 번호를 선택한 뒤 기존 원문 부분문자열·길이·식별정보 검사를 다시 적용했다. 기존 분류 필드는 바꾸지 않았다. 50/50은 의미상 정답 100%가 아니다. 사람 정답 기반 분류 정확도는 미측정이며 38개 조사 사례 통계 백테스트와 단위·목적이 다르다. 7,502건 전체 실행은 아직 하지 않았다. 비용은 사용량 원장 전체 검산 후 갱신하며 이번 PDF 본문에는 전체 추정액을 넣지 않는다.

## 전체 실행 승인 이후의 상태

사용자는 고정 시험 완료 후 전체 7,502건과 데모 상황 요약의 추가 실행을 $50 범위에서 승인했다. 현재 PDF는 50건 시험 완료 중간 검토본이며 전체 실행 결과는 아직 반영하지 않았다. 승인 사실을 완료로 표현하지 않는다. 새 실측 결과가 나오면 별도 갱신한다.
