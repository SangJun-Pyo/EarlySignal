# EarlySignal 발표 검토본

2026-10-09 실제 키워드 제품·공개 배포 요청서 저장·통계 검증을 반영한 **DRAFT**다. 예선에서도 월별 집계와 포아송 규칙을 본문 두 장으로 설명하고, LLM 분류·백테스트·미래 접수 차단을 구분한다. 사람 정답 검수·전체 LLM 적용·현업 효과는 미완료다.

## 두 버전

| 파일 | 구성 | 시간 |
|---|---|---|
| `output/pdf/EarlySignal-preliminary-4min-DRAFT.pdf` | 본문 12장 + 상세 부록 7장 | 발표·데모 240초 |
| `output/pdf/EarlySignal-finals-10min-DRAFT.pdf` | 본문 12장 + 상세 부록 10장 | 발표·데모 480초 + 질의응답 120초 |

부록은 시간 외 참고자료다. 실제 타이머 리허설을 통과했다는 뜻은 아니다. 예선 제품 조작은 50초로 편성했으며, 동일 버전의 시연 또는 녹화로 확인해야 한다.

## 이번 보강

- 실제 SONATA 화재·과열 월별 집계: 직전 12개월 82건, 평균 6.83건, 2018년 8월 17건·2.49배. 접수월과 다음 달 1일의 확인 가능 시점을 설명한다.
- 포아송 상위 꼬리: `P(X ≥ 17 | 평균 6.8333) = 0.0007412096`. 확률 분포는 모형 가정이고 막대그래프는 실제 건수다. 확대 꼬리에는 별도 세로축을 표시한다.
- dev/holdout·사례/대조의 실제 분자·분모를 그린다. 38회 완료월 재계산과 64개 칸 독립 검산, 포아송 적합성 미검증을 서로 구분한다.
- 비교용 이항 계산·차종월당 경보량·단일 차종 민감도 분석도 부록에 포함한다. 주 경보는 포아송이며 발표를 위해 파이프라인 규칙을 변경하지 않았다.
- LLM 직접 분류→출력 검사→캐시→집계 흐름을 설명한다. 고정 50건 모두 API 출력 검사를 통과했다. 초기 인용 실패 14건은 원문 후보 번호 재선택으로 해결했다. 50/50은 실행·출력 검사 결과이며 사람 정답 기반 분류 정확도는 미측정이다. 38개 조사 사례의 통계 백테스트와도 다른 검증이다. 전체 7,502건 처리는 아직 실행하지 않았다.
- 조사 가설·정비 기록·검사로 확인하는 후속 흐름은 ADR-019와 연결해 부록으로 추가했다. 실제 가설 생성·자료 연결·원인 확인 기능은 미구현이며 효과 수치를 붙이지 않았다.
- pgvector/RAG는 현재 미사용이다. 원래 제출 기획의 유사 과거 사례가 미구현임을 밝히고, 분류 검증 후 근거 검색을 보완하는 사용자 승인 설계를 ADR-016과 연결한다.
- 제출 기획→현재 구현→차이·이유→다음 검증 표를 ADR-017과 연결했다. 별도 부품 추출도 미구현이며 요청서는 원래 담당자 결정을 구체화한 결과물이다.
- [공개 제품](https://earlysignal.pages.dev/)의 실제 저장·다운로드 화면으로 교체했다. 캡처의 저장 시각은 2026-10-09 11:13:23 KST, 분석 가능일은 2018-09-01이다.

## 파일

- `build_decks.py`: ReportLab 편집 원본. 공개 결과와 그래프 수치 JSON을 읽는다.
- `figures/build_stat_figures.py`: 실제 집계와 포아송/이항 확률을 읽고 다시 그리는 원본.
- `figures/source.json`: 월별 수치·확률·분모·검산·원본 SHA256·가정의 범위.
- `storyboard.json`: 본문·부록·근거 ID·초 단위 배분.
- `speaker-notes.md`: 240초/480초 시간표와 설명, 50초 시연안, 상세 Q&A.
- `evidence-manifest.md`: 주장·실측·한계·외부 기술 근거.
- `qa.json`: 페이지·시간·글리프·해시·시각 검수 기록.
- `SESSION.md`: 작업 결정과 수정 이력.
- `assets/screenshots/request-public.jpg`: 공개 배포에서 확정·저장한 원본 캡처.

## 재생성

Python 3.10+와 `reportlab`, `matplotlib`, `scipy`, `numpy`가 필요하다. 그래프와 PDF는 로컬 결과만 읽으며 API를 호출하지 않는다.

```bash
python docs/presentation/figures/build_stat_figures.py
python docs/presentation/build_decks.py
```

PDF 결과는 `docs/presentation/output/pdf/`에 저장한다. 이미지 원본을 수정하지 않고 PDF의 표시 영역 안에 배치했다. 최신 두 PDF의 총 41페이지를 Poppler로 렌더링해 확인했다. 폰트는 IBM Plex Sans KR이며 `assets/OFL.txt`에 라이선스가 있다.
