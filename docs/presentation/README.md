# EarlySignal 발표 검토본

2026-10-09 현재 키워드 제품의 실측 결과와 실제 요청서 저장 화면을 반영했다. AI 라벨 시험·사람 정답 검수·현업 효과는 미완료이므로 **DRAFT** 표시를 유지한다. 제품과 데이터가 바뀌면 재생성하고 최종 배포 환경에서 시연을 확인한다.

## 두 버전

| 파일 | 구성 | 시간 |
|---|---|---|
| `output/pdf/EarlySignal-preliminary-4min-DRAFT.pdf` | 예선 9장, 요청서 저장 중심 시연 | 발표·데모 240초 |
| `output/pdf/EarlySignal-finals-10min-DRAFT.pdf` | 결선 본문 12장 + 검증 부록 4장 | 발표·데모 480초 + 질의응답 120초 |

결선 부록은 질의응답에서 필요한 경우에만 연다. 본문 종료 화면에 8분 발표 종료와 2분 질의응답을 표시했다. 시간표는 편성안이며 실제 리허설 통과 기록은 아니다.

## 확인한 결과와 미완료 항목

- `meta.json`, `cases.json`을 직접 읽어 개발용 사례 9/19·대조 0/19, 검증용 사례 7/19·대조 1/17을 표시한다. 현대 209일·기아 240일, 볼트 EV 놓침도 함께 공개한다.
- 이 결과는 키워드 기준선으로 선정된 과거 사례를 평가한 값이다. 일반 정확도나 실제 사고 예방 효과로 표현하지 않는다. 현재 파일의 접수일로 재현했으며 당시 공개·수정 이력은 복원하지 않았다.
- 미래 접수 차단 재계산은 38개 조사 사례의 기준일에서 완료월 경보가 일치했다. 별도 검수에서 64개 표본 칸의 계산도 일치했다. 두 검사는 서로 다른 범위다.
- 실제 브라우저에서 확정한 요청서 캡처를 예선 4장·결선 5장에 넣었다. 원본 이미지를 변경하지 않고 PDF 안에서 필요한 영역을 확대 표시했다.
- AI 시험은 고정 50건 중 6건 성공한 상태를 반영했다. 요청 한도로 시험을 마치지 못했으며 전체 라벨링·정확도·전체 비용은 미검증이다. 제품 화면은 키워드 기준선이다.
- 모델 간 일치율과 사람 정답 기반 정확도를 구분한다. 사람이 확정한 정답이 없으므로 정확도 수치를 만들지 않았다.
- 도입 대상은 사용자가 승인한 **자동차 회사의 고객 안전 담당자**다. 검토 시간·요청서 활용·지속 사용·구매 의사는 파일럿에서 확인할 가설이다.

## 편집·검수 파일

- `build_decks.py`: ReportLab 원본. 결과 JSON과 실제 캡처를 읽어 생성한다.
- `storyboard.json`: 생성된 슬라이드의 내용·근거 ID·시간. 결선 본문과 부록을 구분한다.
- `speaker-notes.md`: 시간표, 발표 문장, 데모 조작안, 질의응답 근거.
- `evidence-manifest.md`: 주장별 출처·실패·미검증 가정.
- `qa.json`: 페이지·시간·글리프·출처 해시·시각 검수 기록.
- `SESSION.md`: 작업 지시와 수정·검수 기록.
- `assets/screenshots/`: 실제 제품 화면. 요청서 저장 시각은 2026-10-09, 분석 시점은 2018년 8월로 구분한다.
- `assets/`: IBM Plex Sans KR 글꼴과 OFL 라이선스.

## 재생성

Python 3.10+와 `reportlab`이 필요하다. 경로는 원본 파일 위치를 기준으로 처리하며 API나 외부 네트워크를 호출하지 않는다.

```bash
python -m pip install reportlab
python docs/presentation/build_decks.py
```

```bash
python docs/presentation/build_decks.py --output-dir output/pdf --font-dir docs/presentation/assets
```

글꼴은 [IBM 공식 저장소](https://github.com/IBM/plex/tree/master/packages/plex-sans-kr/fonts/complete/ttf/hinted)에서 가져왔다. 최신 생성 후 두 PDF의 모든 페이지를 Poppler로 PNG 렌더링하고 시각 검수했다. 이미지 안의 제품 전체 텍스트를 슬라이드에서 읽는 구성은 아니며, 본 시연에서 원문과 내려받은 문서를 직접 연다.
