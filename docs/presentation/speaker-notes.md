# 발표자 노트 · 실측 반영 검토본

일반 심사위원에게 **자동차 회사에서 고객 안전을 살피는 담당자**의 이야기로 설명한다. 예선 4분, 결선은 사용자가 선택한 **8분 발표·데모 + 2분 질의응답**으로 편성했다. 결선 검증 부록은 질문에 따라 열며 본문 시간에 더하지 않는다. 시간표는 실제 리허설 통과를 뜻하지 않는다.

현재 제품 화면은 **키워드 기준선**이다. AI 시험의 일부 성공을 전체 제품에 AI가 적용된 상태로 소개하지 않는다. 아래 대본은 `llm_pilot.json`의 50건 중 6건 성공 상태를 기준으로 하므로 시험 결과가 바뀌면 해당 문장을 함께 갱신한다.

## 질의응답에 사용할 정확한 범위

- **공식 조사보다 먼저라는 의미:** 월 경보 다음 달 첫날과 공식 조사 개시일의 차이다. 주 경보 발생 지표는 접수월 기준 사전 기간이며, 확인 가능일 기준 민감도 분석과 다르다. 실제 조사를 앞당긴 효과는 미검증이다.
- **미래 정보 차단 검사:** 38개 조사 사례 각각에서 잘라 재계산했다. 실행 수는 38건이고 중복 날짜를 제거한 서로 다른 cutoff 날짜는 33개다. 공식 조사 결과 필드는 탐지 입력에 쓰지 않는다.
- **대조군 경보:** 해당 기간 조사 기록이 없던 차종이다. 안전 문제가 없다는 완전한 음성 정답이 아니므로 일반 오탐률로 부르지 않는다.
- **판매량과 노출:** 차종 자신의 과거와 비교하지만 판매·운행 노출, 보도, 계절성 변화를 직접 모델링한 것은 아니다.
- **차종 중복과 평가 단위:** 개발·검증에 겹치는 차종이 있다. 여러 차종을 묶은 사례와 단일 대조의 기회도 다르다. 단일 차종 보조 분석은 사례 8/20·대조 1/19이며 원래 결과를 보존했다.
- **실패:** 볼트 EV는 현재 키워드 기준선에서 missed다. 사전 시제품의 late와 다른 결과를 그대로 공개했다. 이 결과를 보고 임계값이나 키워드를 맞추지 않았다.
- **AI 시험과 비용:** 50건 중 6건 성공은 구조와 인용 검사 통과다. 사람 정확도는 미측정이다. 일부 실행에서 사용량 응답 10회·입력 8,349토큰·출력 1,230토큰·추정 $0.0053076이 확인됐지만 전체 비용·실제 청구액·처리량 추정으로 확대하지 않는다. 자세한 실행 범위는 근거표 E13을 연다.
- **개인정보:** 알려진 식별값과 패턴에 대한 정제·검사를 적용했다. 검출 0건을 완전한 익명화 보증으로 설명하지 않는다.
- **Codex 효과:** 문서번호 충돌·잘못된 인용·시간 경계 등 실제 검수 지적과 수정·재검증을 제시한다. 에이전트 수와 토큰 자체를 성과로 삼지 않는다.
- **사업성:** 도입 대상과 운영 계획은 제안이다. 구매·계약·유료 사용·현업 시간 절감을 확인하지 않았다. 파일럿의 계속 사용할 이유를 검증한다.

## 리허설과 녹화

최종 배포 버전에서 예선 4분과 결선 본문 8분을 직접 재어 본다. 네트워크 장애에 대비할 녹화본도 동일 데이터 버전의 원문 검토·제외·요청서 저장·다운로드 열기까지 포함한다. 현재 자료는 녹화나 리허설이 완료되었다는 기록이 아니다. 데모 기록을 지우기 전 필요한 Markdown·JSON을 내려받아 보존한다.
