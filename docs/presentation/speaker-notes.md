# 발표자 노트 · 고객의 목소리를, 조사의 근거로.

문서 상태: 발표자료. 파일명은 기존 링크를 유지하며 내부 초안 표기는 제거했다.

최종 발표자료의 예선 본문은 **9장·240초**, 그중 실제 데모는 **60초**다. 월별 추이와 포아송은 본문5·6장의 두 장을 유지한다. 결선은 같은9장에 설명을 더해 **480초+질의응답120초**다. 시간은 배분안이며 타이머 리허설 실측이 아니다. 예선은 공통부록9장, 결선은 공통9장+추가3장을 시간 외 자료로 둔다.

현재 제품은 LLM 분류7,502건의 출력 검사 완료 결과를 사용한다. 출력 검사 통과·방법 일치율·38사례 키워드 통계 백테스트·사람 정답 정확도는 서로 다른 검증이다. 독립30건 검수 자료를 준비하고 사용자가 시도했지만 전문성·시간 제약으로 당일 미완료했다. 사람 정답0건, 정확도 미측정이며 AI를 정답으로 대체하지 않는다.

## 통계 질의응답

- **포아송 p값:** 모형을 가정했을 때 관측 건수 이상이 나올 상위 꼬리 확률이다. 해당 차종의 결함 확률, 일반 오탐률, 전체 오류율이 아니다. 독립·동일 발생률·평균과 분산 동일이라는 가정의 적합성은 검증하지 않았다.
- **월별 기준선:** 직전 12개월(당월 제외, 0건 월 포함), 최소 6개월 이력, 평균 하한 0.5. 실제 예시는 59/12=4.9166667이며 17건의 p=0.000016130219674이다. 막대그림은 실제 건수, 확률그림은 이 평균을 가정한 이론 모형이다.
- **이항 비교:** 직전 기간 전체 신고 중 해당 증상의 비율을 기준으로 이번 달 전체 신고 중 비율 증가를 계산한다. 코드에서 비교용으로 계산하지만 현재 제품의 주 경보와 주 평가에는 포아송만 사용한다. 발표를 위해 규칙을 바꾸지 않았다.
- **주 지표:** 경보 접수월 m이 조사일−12개월 이상, 조사일−1개월 미만인 범위에서 표적 범주의 경보가 발생한 사례 비율이다. 사례는 여러 차종 묶음일 수 있고 대조는 단일 차종이다.
- **선행 일수:** 경보 접수월 다음 달 첫날과 지정 조사 기록 개시일의 차이다. 현대·기아의 209일·240일은 PE19-003·004의 2019-03-29 개시일을 비교한 값이다. 앞선 청원·검토가 있어 기관의 최초 인지·최초 조사 또는 AI 최초 발견을 뜻하지 않는다. 실제 당시 운영·조사 착수·사고 예방 효과가 아니다. 사후 늦은 경보 검색에도 완료월 제약을 적용한다.
- **키워드 38회·64칸:** 38개 조사 사례(고유 cutoff 33개)의 완료월 재계산과 64개 표본 칸의 기준선·확률·경보 독립 검산은 서로 다른 검사다. 둘 다 의미 정확도나 분포 적합성 검사가 아니다.
- **대조군:** 해당 기간 조사 기록이 없던 차종이다. 문제가 전혀 없다는 음성 정답이 아니며 작은 신고량·차종 중복 한계가 있다.
- **업무량:** 0.199와 0.092는 등록 평가창의 차종·월당 증상별 경보 수다. 전사 월간 경보 총수나 현업 검토 시간으로 환산하지 않는다.
- **민감도 분석:** 단일 차종 사례 8/20·대조 1/19를 별도 보고한다. 주 분석과 합치거나 유리한 결과로 교체하지 않는다.

## AI와 검색 질의응답

- **분류:** 16개 증상 중 주 라벨 1개와 보조 최대 2개, 위험 요소 6개, 심각도 1~3, 원문 인용과 한국어 요약을 출력한다. 인용은 송신 원문에 실제 존재해야 하며 형식·길이·식별정보를 검사한다. 스키마 준수는 의미 정확도가 아니다.
- **현재 기술:** Structured Outputs 직접 분류다. pgvector나 벡터 검색은 구현·사용하지 않는다. 대표 신고 선택은 AI가 번호 1~3개만 고르고 코드가 기존 요약을 그대로 연결한다. 18개 중 16개 공개, 2개 수량 검사 거부다.
- **정확도:** 같은 표본에서 키워드·LLM을 사람이 확정한 정답과 대조해야 한다. 모델 간 일치율을 정확도로 부르지 않는다. 검수 예시로 지침을 개선한다면 개발용과 최종 평가 표본을 분리한다.
- **승인한 보완 설계:** 유사 과거 사례는 원래 제출 기획에 포함됐지만 현재 미구현이다. RAG는 유사 과거 신고·수리 자료의 근거 검색 보조다. 다른 신고 사실을 현재 신고의 자동 라벨에 섞지 않는다. 임베딩→pgvector 기준일·권한 필터 검색→출처 연결 요약→담당자 대조를 계획한다. 실제 API·DB 추가 구현은 승인 범위에 포함하지 않는다.
- **검색 검증 계획:** 사람이 표시한 관련 자료 대비 Recall@k, 기준일·권한 누출, 인용의 원문·의미 정확성, 검토 시간을 측정한다. 현재 실측값은 없다.
- **비용:** 누적 라벨 $4.5448836 + 요약 $0.0292060 = 총 $4.5740896이다. 실패와 진단까지 포함한 반환 사용량 추정이며 실제 청구액은 아니다. 새 요약 선택만은22응답 $0.0071512다. 처리량으로 외삽하지 않는다. 전체 분류와 대표 요약의 실제 사용량을 합산한다. 실제 계정 청구액과 다를 수 있으며, 초기 사용량 일부의 캐시 연결 누락 때문에 검증된 건당 단가는 미측정이다.


## 제출 전 확인

두PDF와 공개데이터·캡처가 같은 버전인지 확인한다. 예선4분·결선8분을 실제로 재고 동일버전 장애 대비 녹화를 준비한다. 리허설·녹화와 전문가 정답 검수는 아직 미완료다. 유사 과거 사례 검색·별도부품추출·가설생성은 미구현이다. 2024년 기간 확장은 후속 실험으로 남긴다.

## 실제 사건 맥락과 지정 PE 비교

[NHTSA PE19-003 개시서](https://static.nhtsa.gov/odi/inv/2019/INOA-PE19003-2613.PDF)와 [PE19-004 개시서](https://static.nhtsa.gov/odi/inv/2019/INOA-PE19004-4727.PDF) 1쪽에 따르면 2018-06-11 CAS가 현대·기아 비충돌 화재 조사를 청원했고, 2018-08-21 DP18-003 청원 검토가 열렸다. 그에 앞서 현대RQ17-004·기아RQ17-003 리콜 검토도 있었다. 2019-03-29의 PE 개시는 이 이력 뒤의 지정 비교 지점이다. 2018년 신고가 증가한 모습을 사후 재현한 것이며 기관보다 먼저 알아냈거나 모든 신고가 같은 원인이라는 주장은 하지 않는다. 사건 이력은 탐지 입력에 추가하지 않는다.

[18V-934 공식 안내문](https://static.nhtsa.gov/odi/rcl/2018/RCONL-18V934-4890.pdf)은 특정 기존 리콜의 엔진 교체 과정에서 고압 연료관이 손상·정렬 불량·체결 불량으로 연료 누출과 화재 위험을 낳을 수 있어 연결부를 검사하고 필요시 교체한다고 설명한다. 이는 별도로 확인된 실제 문제의 예이며 데모의 모든 신고 원인으로 연결하지 않는다. 2024년까지 기간을 넓히는 것은 사용자가 정한 후속 실험이며 현재 발표 범위에 넣지 않는다.

연료관 리콜의 첫 제출은 [기아18V907](https://static.nhtsa.gov/odi/rcl/2018/RCLRPT-18V907-3425.PDF) 2018-12-19, [현대18V934](https://static.nhtsa.gov/odi/rcl/2018/RCLRPT-18V934-2602.PDF) 2018-12-28이다. 각 보고서1~2쪽의 범위는 이전 리콜로 엔진을 교체한 차량 일부이며, 고압 연료관 손상·정렬 불량·체결 불량으로 누유·화재 위험이 생길 수 있다는 내용이다. 이 건의 모집단·누적 신고 수를 현재 월별 데모 수치와 섞지 않는다. 부록4에는 별도 실제 문제라는 한 문장만 넣었다.
